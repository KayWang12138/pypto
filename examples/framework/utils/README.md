# 框架打印配置样例 (Framework Configuration)

本目录展示了如何调整 PyPTO 框架的全局配置，以优化调试输出和运行行为。

## 总览介绍

在算子开发和测试阶段，控制输出信息的详略程度对于定位问题至关重要。本目录主要涵盖：
- **打印选项设置**: 演示如何配置张量在控制台显示的样式、精度和截断策略。

## 样例代码特性

- **自定义显示**: 展示了如何通过 `pypto.set_print_options` 调整浮点数精度 (`precision`) 和显示项数 (`edge_items`)。
- **防止日志爆炸**: 展示了如何利用 `threshold` 参数在处理超大张量时自动进行内容截断。
- **格式化布局**: 演示了如何根据终端宽度调整 `linewidth`。

## 代码结构

- **`print.py`**: 展示了各种打印配置选项的端到端示例。

## 运行方法

### 执行脚本

```bash
python3 print.py
```

## 注意事项

- 框架层面的打印选项主要影响 PyPTO 内部张量对象（如通过 `pypto.tensor` 创建的符号张量）在 `print()` 时的表现。
- 为了获得最佳性能，建议在生产环境下将打印阈值调低。
