# Beginner Examples

Welcome to the beginner examples! These examples are designed for users who are new to PyPTO.

## Overview

These examples introduce fundamental PyPTO concepts and operations. They are simple, well-documented, and perfect for getting started.

## Examples
### [00. Introduction](00_introduction/)
### [01. Basic Operations](01_basic_operations/)

Learn the fundamentals of PyPTO:
- Tensor creation and properties
- Basic loop and conditions usage
- Element-wise operations (add, mul, sub, div)
- Matrix multiplication
- Activation functions
- View operations for tiling
- Combining multiple operations

**Difficulty**: ⭐ Beginner
**Time**: 15-20 minutes
**Prerequisites**: PyPTO installation, CANN environment

## Learning Path

1. Start with [Introduction/Basic Operations](00_introduction/01_basic_operations/) to understand core concepts
2. Move to [Intermediate Examples](../intermediate/README.md) once comfortable
3. Check the [User Guide](../../docs/user/README.md) for detailed explanations
