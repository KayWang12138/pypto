# Model Examples

Real-world model implementations using PyPTO.

## Overview

These examples demonstrate how PyPTO is used in production model implementations. They show complete, optimized implementations of model components.

## Examples

### [Qwen3](qwen3/)

Qwen3 model component implementations:
- Attention preprocessing
- RMS normalization
- FFN/MLP layers
- Expert selection
- Token table operations

**Difficulty**: ⭐⭐⭐ Advanced  
**Use Case**: Production model implementation  
**Prerequisites**: All educational examples

## Structure

Model examples are organized by model name. Each model directory contains:
- Component implementations
- Test files
- Documentation

## Usage

These examples are reference implementations for:
- Understanding production patterns
- Learning optimization techniques
- Seeing real-world usage

**Note**: These examples are more complex than educational examples and assume familiarity with the models and PyPTO.

## Contributing

New model examples are welcome! Please follow the structure of existing examples and include:
- Clear documentation
- Test cases
- Performance notes
