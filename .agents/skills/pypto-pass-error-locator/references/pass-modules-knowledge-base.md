# PyPTO Pass 模块知识库

本文档详细介绍了 PyPTO 中常见的 Pass 模块及其功能、常见错误、可能原因和修复建议。

## 常见 Pass 模块及错误模式

### 1. RemoveRedundantReshape

**功能描述**：删除冗余的reshape操作（当所有消费者都是reshape时）

| 常见错误 | 可能原因 | 修复建议 |
|---------|---------|---------|
| 输入输出操作数无效 | 输入输出操作数数量不为1 | 检查reshape操作的输入输出tensor数量，确保为1 |
| 消费者为空指针 | 消费者为空指针或已被删除 | 验证tensor的消费者列表，确保消费者存在且有效 |
| 操作已删除标记错误 | 操作已被其他pass标记为删除 | 检查pass执行顺序，避免重复删除操作 |

---

### 2. AutoCast

**功能描述**：自动插入类型转换操作（BF16/FP16/INT32-FP16）并优化冗余CAST链

| 常见错误 | 可能原因 | 修复建议 |
|---------|---------|---------|
| 获取InOutCast连接tensor失败 | INCAST/OUTCAST节点连接问题 | 检查INCAST/OUTCAST节点的连接关系，确保tensor正确连接 |
| 插入BF16/FP16/INT32-FP16 CAST失败 | 架构不支持某些数据类型 | 确认NPU架构支持目标数据类型，检查数据类型转换路径 |
| 冗余CAST链消除失败 | CAST链优化过程中图结构问题 | 验证CAST链的图结构，确保优化算法正确处理链式结构 |

---

### 3. InferMemoryConflict

**功能描述**：推断内存冲突并插入register copy

| 常见错误 | 可能原因 | 修复建议 |
|---------|---------|---------|
| 前向/后向传播失败 | ViewType输入输出tensor的数据类型不在viewType表中 | 检查tensor的数据类型，确保在支持的viewType表中 |
| 插入Copy失败 | 输入输出tensor的raw size不相等且不匹配特定reshape pattern | 验证输入输出tensor的raw size，检查reshape pattern匹配 |
| 推断tile shape失败 | tile shape维度与输入shape维度不等或大小为0 | 检查tile shape的维度和大小，确保与输入shape兼容 |

---

### 4. RemoveUndrivenView

**功能描述**：删除无驱动的view操作（将OP_ASSEMBLE_SSA降级为OP_ASSEMBLE并删除无驱动的OP_VIEW）

| 常见错误 | 可能原因 | 修复建议 |
|---------|---------|---------|
| 缺少INPLACE_IDX属性错误 | OP_ASSEMBLE_SSA缺少INPLACE_IDX属性 | 为OP_ASSEMBLE_SSA操作添加INPLACE_IDX属性 |
| 生产者数量无效错误 | 输入操作数的生产者数量不为1 | 检查输入操作的生产者数量，确保为1 |
| 生产者类型错误 | 生产者类型不是OP_VIEW | 验证生产者操作类型，确保为OP_VIEW |

---

### 5. ExpandFunction

**功能描述**：将tensor graph扩展为tile graph

| 常见错误 | 可能原因 | 修复建议 |
|---------|---------|---------|
| 操作验证失败 | 输入输出操作数为空指针 | 检查操作的输入输出tensor，确保不为空指针 |
| 操作展开失败 | 操作不支持展开 | 验证操作类型是否支持展开，检查scope配置 |
| Scope混合错误 | 在CV分离平台上混合Cube和Vector操作 | 检查平台配置，避免在CV分离平台上混合Cube和Vector操作 |

**功能描述**：合并连续的view/assemble操作链

|---------|---------|---------|
| 合并view/assemble链失败 | 获取view/assemble属性失败或操作链中存在空指针 | 检查view/assemble操作属性，验证操作链完整性 |
| 计算合并offset失败 | offset计算失败或tensor offset添加失败 | 验证offset计算逻辑，确保tensor offset正确添加 |
| 删除冗余assemble失败 | 链首操作没有输入操作数或链尾操作没有输出操作数 | 检查操作链的完整性，确保首尾操作正确连接 |

## 使用说明

本文档作为 PyPTO Pass 模块错误定位的参考手册，当遇到 Pass 模块错误时：

1. 根据错误日志中的 Pass 模块名称查找对应的条目
2. 查看"常见错误"列，了解可能出现的错误类型
3. 查看"可能原因"列，分析错误产生的根本原因
4. 查看"修复建议"列，获取具体的修复指导
5. 结合具体错误信息和堆栈跟踪，定位问题代码位置
6. 参考修复建议进行问题修复

## 注意事项

- 不同版本的 PyPTO 可能存在 Pass 模块差异
- 部分错误可能由多个 Pass 模块共同导致
- 错误信息中的行号和文件路径是定位问题的关键
- 建议结合代码审查和单元测试进行问题修复
- 修复建议提供了通用的解决思路，具体实施时需结合实际情况
