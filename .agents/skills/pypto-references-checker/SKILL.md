# PyPTO References 一致性检查

检查 `.agents/skills/*/references/` 下的文件与 `docs/` 目录的一致性，识别需要修复的问题。

## 核心原则

### 以 docs 为标杆

- **错误**：与 docs 事实矛盾（如虚构不存在的 API、错误的参数说明）
- **歧义**：表述可能被误解（如概念混淆、术语不一致）
- **模糊**：关键信息不清晰（如遗漏重要类型、路径不完整）

### 不死脑筋

以下情况**不属于问题**：

| 类型 | 说明 |
|------|------|
| 合理简化 | 速查表用简化写法并指向 docs 获取详情 |
| 更严格规范 | skill 定义比 docs 更严格的约束（如字符限制） |
| 无对应 docs | 内部模板、评审规则等无 docs 对应的内容 |

## 工作流程

### 阶段 1：扫描与规划

1. 扫描所有 skill 的 references 目录
2. 统计文件数量，按 skill 分组
3. 确定检查优先级（核心 skill 优先）

```bash
# 扫描命令
find .agents/skills -type d -name "references" -exec sh -c 'echo "=== {} ===" && ls {}' \;
```

### 阶段 2：并行检查

按 skill 并行检查，每个 skill 的检查步骤：

1. **读取 references 文件**：获取文件内容
2. **识别关键实体**：提取 API 名称、路径、参数、命令、代码示例等
3. **搜索 docs 验证**：在 docs 中搜索对应内容
4. **对比分析**：识别不一致、错误、歧义

**验证要点**：

| 实体类型 | 验证方法 |
|----------|----------|
| API 名称 | `grep "pypto\.<api>" docs/` |
| 文件路径 | 检查路径是否存在 |
| 参数/选项 | 对比 docs 中的参数说明 |
| 命令格式 | 对比 docs 或脚本帮助文档 |
| 代码示例 | 检查语法正确性，尤其是API使用是否正确 |

### 阶段 3：问题分类

对发现的问题进行分类：

| 分类 | 定义 | 处理 |
|------|------|------|
| **P0 必须修复** | 事实性错误、代码错误、路径错误 | 列入修复清单 |
| **P1 建议修复** | 概念歧义、术语不一致 | 列入建议清单 |
| **P2 可选修复** | 模糊描述、简化不当 | 记录但不强求 |
| **无需修复** | skill 自身知识、合理简化 | 从报告中剔除 |

### 阶段 4：二次检查

对 P0/P1 问题进行二次验证：

1. **确认错误存在**：重新读取文件确认问题位置
2. **排除特殊情况**：检查是否有上下文说明、执行环境差异
3. **检查联动修改**：确认修复后是否需要修改 skill 内其他文件

### 阶段 5：生成报告

使用 `templates/report-template.md` 生成检查报告。

## 常见问题类型

常见问题类型详见 [references/common-issues.md](references/common-issues.md)，用于识别问题类型和判断严重程度，在阶段 3 分类时参考。主要类型：

- 代码错误（语法错误、笔误）
- 路径错误（相对路径错误、文件不存在）
- API 错误（虚构 API、API 名称错误）
- 参数错误（与 docs 矛盾、遗漏选项）
- 概念歧义（术语不一致、概念混淆）

## 检查清单

检查清单详见 [references/checklist.md](references/checklist.md)，用于逐项验证，在阶段 2 检查时按清单执行。

## 输出格式

### 问题记录格式

```markdown
### 问题 N：<简短标题>

- **文件**：`<相对路径>:<行号>`
- **类型**：P0/P1/P2
- **问题**：<具体内容>
- **docs 对比**：<docs 中的正确内容，如有>
- **修复建议**：<具体修复方案>
- **联动修改**：<需要同步修改的其他文件，如有>
```

### 报告结构

1. 检查概况（skill 数量、文件数量、问题统计）
2. 问题详情列表（按 P0/P1/P2 分组）
3. 修复建议汇总
4. 无需修复项说明

## 完成标准

- 所有 skill 的 references 已检查
- P0 问题全部确认并列出
- 每个问题有明确的修复建议
- 联动修改已识别
