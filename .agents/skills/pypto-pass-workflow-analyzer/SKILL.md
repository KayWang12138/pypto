# PyPTO Pass 业务流分析技能

## 概述

本技能用于分析 PyPTO pass 文档中的业务流程设计部分，帮助理解某个业务场景中各个 pass 模块在当前场景中的职责、执行顺序依赖关系及数据流转过程。

## 适用场景

当需要理解以下内容时使用此技能：
- 某个业务场景（如冗余op消除、切图合图、动态参数处理等）的完整执行流程
- 业务流程中涉及的各个 pass 模块及其作用
- 各 pass 模块的执行顺序和依赖关系
- 各 pass 模块之间的数据流转和状态传递

## 触发关键词

- **分析pass XXX业务流程**：分析指定业务中pass执行的完整业务流
- **分析XXX业务的pass执行流程**：分析指定业务中pass执行的完整业务流
- **分析XXX业务涉及哪些pass**：分析指定业务中涉及的pass模块及执行的完整流程
- **分析pass xxx的数据流变化**：分析指定业务涉及pass的数据流转过程

## 工作流程

### 步骤1：定位业务流程文档

1. 在用户指定文档目录下查找相关业务流程文档（如果有的话）
2. 根据描述的业务场景，在 `docs/` 文档目录中查找相关业务流程文档

### 步骤2：解析业务流程设计

从文档中提取以下信息：

1. **业务场景描述**
   - 业务名称和目标
   - 业务触发条件
   - 业务适用范围

2. **涉及的 Pass 模块**
   - 列出所有参与的 pass 模块
   - 每个 pass 的名称和基本功能

3. **执行顺序**
   - Pass 的执行序列
   - 执行阶段划分（如：tensor_graph阶段优化、tile_graph阶段优化、block_graph阶段优化）

4. **依赖关系**
   - Pass 之间的前置依赖
   - 数据依赖关系
   - 状态依赖关系

5. **数据流转**
   - 各 pass 的输入输出
   - 中间数据的传递方式

### 步骤3：结合源代码验证

1. 在 `framework/src/passes/` 中查找相关 pass 的源代码
2. 使用 `pypto-pass-module-analyzer` 技能分析相关pass功能，验证文档描述与代码实现的一致性
3. 补充文档中未详细说明的实现细节

### 步骤4：生成业务流分析报告

按照 `REPORT_TEMPLATE.md` 中的模板格式输出分析结果。该模板包含以下章节：

1. 业务概述
2. 涉及的 Pass 模块（表格形式）
3. 执行流程（包含整体流程图和详细执行顺序）
4. 依赖关系分析（前置依赖、数据依赖、状态依赖）
5. 各 Pass 详细说明
6. 业务价值
7. 典型应用场景
8. 注意事项
9. 相关文件

## 输出要求

1. 使用清晰的层级结构
2. 使用表格展示 pass 列表
3. 使用流程图或列表展示执行顺序
4. 详细说明每个 pass 的功能和依赖关系
5. 提供实际的应用场景示例

## 注意事项

1. 如果文档信息不完整，结合源代码补充
2. 如果发现文档与代码不一致，标注出来
3. 重点关注 pass 之间的依赖关系和数据流转
4. 对于复杂的业务流程，分阶段详细说明
