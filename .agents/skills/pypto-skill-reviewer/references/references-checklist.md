# References 检查清单

## 一、文件基础检查

| 检查项 | 说明 |
|--------|------|
| 文件是否存在 | references 中引用的文件路径是否真实存在 |
| 相对路径正确 | 文件间相互引用的相对路径是否正确 |
| 编码格式 | 是否使用 UTF-8 编码 |

## 二、内容正确性检查

### 2.1 API 相关

| 检查项 | 验证方法 |
|--------|----------|
| API 名称正确 | `grep "pypto\.<api>" docs/api/` |
| 参数列表完整 | 对比 docs/api/ 下对应文档 |
| 参数类型正确 | 对比 docs 中的参数说明 |
| 返回值正确 | 对比 docs 中的返回值说明 |

### 2.2 路径相关

| 检查项 | 验证方法 |
|--------|----------|
| 文件路径存在 | `ls <path>` 或 `test -f <path>` |
| 头文件路径完整 | 检查是否包含项目前缀 |
| 脚本路径正确 | 确认执行上下文（项目根目录 / skill 目录） |

### 2.3 命令相关

| 检查项 | 验证方法 |
|--------|----------|
| 命令格式正确 | 对比 docs 或 `--help` 输出 |
| 参数格式正确 | 检查 `-f=value` vs `-f value` |
| 选项值合法 | 对比 docs 中的可选值列表 |

### 2.4 代码相关

| 检查项 | 验证方法 |
|--------|----------|
| 语法正确 | 检查拼写、括号匹配等 |
| 函数名正确 | 对比官方示例或文档 |
| 常量名正确 | 检查是否与 docs 一致 |

## 三、语义一致性检查

### 3.1 术语一致性

| 检查项 | 说明 |
|--------|------|
| 概念术语 | 是否与 docs/tutorials/appendix/glossary.md 一致 |
| 组件名称 | Tile Graph、Tensor Graph 等是否统一 |
| 参数名称 | 与 docs 中参数名是否一致 |

### 3.2 约束一致性

| 检查项 | 说明 |
|--------|------|
| 硬件约束 | 对齐要求、维度限制等是否与 docs 一致 |
| dtype 支持 | 支持的数据类型列表是否正确 |
| 版本要求 | CANN、PyTorch 版本要求是否正确 |

## 四、排除项（非问题）

以下情况**不需要标记为问题**：

| 类型 | 示例 |
|------|------|
| 合理简化 | "INT8-64" 简写 + 指向 docs 详情 |
| 更严格规范 | skill 定义比 docs 更严格的 commit message 格式 |
| 内部知识 | skill 特有的错误处理经验、troubleshooting 总结 |
| 无对应 docs | 评审规则、模板等 skill 内部内容 |

## 五、联动修改检查

发现问题时，检查是否需要同步修改：

| 检查项 | 说明 |
|--------|------|
| SKILL.md | 是否引用了相同内容 |
| 其他 references | 是否有重复描述 |
| scripts/ | 脚本中是否有相同路径引用 |
