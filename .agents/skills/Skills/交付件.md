# PyPTO Operation 开发交付件清单

## 一、前端接口层（Frontend Interface）

### 1.1 Operation定义文件
**目录**: `framework/src/interface/operation/`

#### 核心文件
- **operation.h / operation.cpp**: Operation基类定义
  - 定义Operation类，包含操作码(opcode)、输入输出操作数(iOperand/oOperand)
  - 提供属性管理机制（SetAttribute/GetAttribute）
  - 支持TileShape管理
  - 提供SSA格式输出和JSON序列化

- **opcode.h / opcode.cpp**: 操作码定义
  - 定义所有支持的操作码枚举（如OP_ADD, OP_MUL, OP_SUB等）
  - 提供操作码与字符串的映射

- **attribute.h / attribute.cpp**: 属性管理
  - 支持多种属性类型：string, bool, int64_t, Element, SymbolicScalar等
  - 提供属性的设置和获取接口

- **operation_common.h / operation_common.cpp**: 公共工具函数
  - 提供Shape推导、数据类型检查等通用功能

#### Vector算子实现目录
**目录**: `framework/src/interface/operation/vector/`

- **binary.h / binary.cpp**: 二元运算（Add, Sub, Mul, Div等）
  - 定义BinaryOpType枚举
  - 实现TiledBinaryOperation模板函数
  - 处理广播(broadcast)逻辑
  - 切分Tile并生成TiledXXX操作

- **unary.h / unary.cpp**: 一元运算（Abs, Exp, Log, Sin等）
  - 定义UnaryOpType枚举
  - 实现TiledUnaryOperation模板函数

- **compare.cpp**: 比较运算（Equal, Greater, Less等）
- **reduction.cpp**: 规约运算（ReduceSum, ReduceMax等）
- **permute.cpp**: 排列运算（Permute, Transpose等）
- **indexing.cpp**: 索引运算（Gather, Scatter等）
- **tensor_transformation.h / tensor_transformation.cpp**: 张量变换（Reshape, Expand等）

### 1.2 Function定义文件
**目录**: `framework/src/interface/function/`

- **function.h / function.cpp**: Function类定义
  - 管理Operation序列
  - 提供AddOperation接口添加操作
  - 支持多种图类型：TENSOR_GRAPH, TILE_GRAPH, EXECUTE_GRAPH等
  - 管理输入输出张量

### 1.3 Tensor定义文件
**目录**: `framework/src/interface/tensor/`

- **logical_tensor.h / logical_tensor.cpp**: 逻辑张量定义
  - 定义LogicalTensor类，包含shape、dtype、format等信息
  - 提供View接口用于Tile切分

## 二、Tile操作层（TileOp Interface）

### 2.1 TileOp定义文件
**目录**: `framework/src/interface/tileop/`

#### Vector操作（调用PTO指令）
**目录**: `framework/src/interface/tileop/vector/`

- **binary.h**: 二元运算Tile操作
  - 定义BinaryComputeImpl模板函数
  - 调用PTO指令：pto::TADD, pto::TSUB, pto::TMUL, pto::TDIV等
  - 支持广播操作：TROWEXPANDADD, TROWEXPANDSUB等

- **unary.h**: 一元运算Tile操作
  - 调用PTO指令：pto::TABS, pto::TEXP, pto::TLOG等

- **cast.h**: 类型转换操作
- **compare.h**: 比较操作
- **reduce.h**: 规约操作
- **permute.h**: 排列操作
- **gather.h / scatter.h**: 索引操作
- **mte.h**: 内存传输操作（CopyIn/CopyOut）

#### Cube操作（矩阵运算）
**目录**: `framework/src/interface/tileop/cube/`

- **cube_pto.h**: 矩阵乘法Tile操作
  - 调用PTO指令：pto::TMATMUL

#### Conv操作（卷积运算）
**目录**: `framework/src/interface/tileop/conv/`

- **conv_pto.h**: 卷积Tile操作

#### 工具文件
**目录**: `framework/src/interface/tileop/utils/`

- **tile_tensor.h**: Tile张量定义
- **layout.h**: 布局管理
- **common_type.h**: 公共类型定义

## 三、代码生成层（Codegen）

### 3.1 Codegen核心文件
**目录**: `framework/src/codegen/`

- **codegen.h / codegen.cpp**: 代码生成主入口
  - 提供CodeGen接口，将Function编译为可执行代码

- **codegen_op.h / codegen_op.cpp**: Operation代码生成基类
  - 定义CodeGenOp基类
  - 提供GenOpCode纯虚函数接口
  - 管理操作数、数据类型、Shape等信息

- **codegen_cce.h / codegen_cce.cpp**: CCE代码生成
  - 生成CCE（Ascend C）代码

- **codegen_factory.h**: 代码生成工厂
  - 根据Operation类型创建对应的CodeGenOp实例

### 3.2 CloudNPU代码生成
**目录**: `framework/src/codegen/cloudnpu/`

- **codegen_op_cloudnpu.h / codegen_op_cloudnpu.cpp**: CloudNPU代码生成基类
  - 继承自CodeGenOp
  - 提供PrintXXX系列函数生成TileOp调用代码

- **codegen_vector_binary.cpp**: Vector二元运算代码生成
  - 实现PrintBinaryStatic函数
  - 生成TileOp调用代码，例如：
    ```cpp
    Binary_<dtype, OS0, OS1, DS, S0, S1, BrcOperand>(dst, src0, src1);
    ```

- **codegen_vector_unary.cpp**: Vector一元运算代码生成
- **codegen_vector.cpp**: Vector通用代码生成
- **codegen_cube.cpp**: Cube矩阵运算代码生成
- **codegen_mte.cpp**: MTE内存传输代码生成
- **codegen_distributed.cpp**: 分布式通信代码生成

### 3.3 辅助管理模块
**目录**: `framework/src/codegen/stmt_mgr/`

- **codegen_for_block.h / codegen_for_block.cpp**: For循环代码生成
  - 生成Tile遍历的循环结构

**目录**: `framework/src/codegen/symbol_mgr/`

- **codegen_symbol.h / codegen_symbol.cpp**: 符号管理
  - 管理变量名、缓冲区ID等符号信息

**目录**: `framework/src/codegen/utils/`

- **codegen_utils.h / codegen_utils.cpp**: 代码生成工具函数
- **parallel_execute.h / parallel_execute.cpp**: 并行执行管理

## 五、关键数据结构

### 5.1 Operation类
```cpp
class Operation {
    LogicalTensors iOperand;      // 输入操作数
    LogicalTensors oOperand;      // 输出操作数
    Opcode opcode;                // 操作码
    TileShape tileShape_;         // Tile形状
    // 属性管理
    void SetAttribute(key, value);
    T GetAttribute(key);
};
```

### 5.2 Function类
```cpp
class Function {
    std::vector<std::shared_ptr<Operation>> operations_;
    void AddOperation(opcode, inputs, outputs);
};
```

### 5.3 LogicalTensor类
```cpp
class LogicalTensor {
    std::vector<int64_t> shape;   // 形状
    DataType dtype;               // 数据类型
    Format format;                // 数据格式
    LogicalTensorPtr View(function, shape, offset);  // Tile视图
};
```

## 六、开发新算子需要交付的文件

### 示例：开发Add算子

1. **Operation定义** (`interface/operation/vector/binary.cpp`)
   - 实现Add函数接口
   - 处理Shape推导和广播
   - 切分Tile并调用TiledBinaryOperation

2. **TileOp定义** (`interface/tileop/vector/binary.h`)
   - 定义BinaryComputeImpl模板
   - 调用pto::TADD指令

3. **Codegen实现** (`codegen/cloudnpu/codegen_vector_binary.cpp`)
   - 实现PrintBinaryStatic函数
   - 生成Binary_<...>(dst, src0, src1)调用代码

4. **Opcode定义** (`interface/operation/opcode.h`)
   - 添加OP_ADD枚举值
