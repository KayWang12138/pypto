# PyPTO Operation 开发流程指南

## 一、开发流程概览

```
用户调用Python API
    ↓
Python前端封装 (python/pypto/op/math.py)
    ↓
C++ Operation接口 (interface/operation/vector/xxx.cpp)
    ↓
Tile切分 (TiledXXXOperation)
    ↓
Function.AddOperation (添加TiledXXX操作)
    ↓
Codegen代码生成 (codegen/cloudnpu/codegen_vector_xxx.cpp)
    ↓
生成TileOp调用代码
    ↓
TileOp执行 (interface/tileop/vector/xxx.h)
    ↓
调用PTO指令 (pto::TXXX)
```

#### 2.3 实现Tile切分函数

```cpp
template <YourOpType T>
void TiledYourOperation(
    Function &function, 
    const TileShape &tileShape, 
    size_t cur, 
    LogicalInput &input, 
    const LogicalTensorPtr &result, 
    TileInfo &resultTileInfo) {
    
    // 递归切分Tile
    if (cur == input.tensor->GetShape().size()) {
        // 到达最内层，创建Tile视图
        auto inputTile = input.tensor->View(function, input.tileInfo.shape, input.tileInfo.offset);
        auto resultTile = result->View(function, resultTileInfo.shape, resultTileInfo.offset);
        
        // 添加Tiled操作到Function
        function.AddOperation(
            GetYourOpNameCode<T>(), 
            {inputTile}, 
            {resultTile}
        );
        return;
    }
    
    // 继续切分下一维度
    auto &vecTile = tileShape.GetVecTile();
    for (int i = 0; i < result->shape[cur]; i += vecTile[cur]) {
        resultTileInfo.offset[cur] = i;
        resultTileInfo.shape[cur] = std::min(
            result->shape[cur] - resultTileInfo.offset[cur], 
            vecTile[cur]
        );
        input.tileInfo.offset[cur] = i % input.tensor->GetShape()[cur];
        input.tileInfo.shape[cur] = std::min(
            input.tensor->GetShape()[cur] - input.tileInfo.offset[cur], 
            vecTile[cur]
        );
        TiledYourOperation<T>(function, tileShape, cur + 1, input, result, resultTileInfo);
    }
}
```

#### 2.4 实现对外接口函数

```cpp
LogicalTensorPtr YourOp(
    Function &function, 
    const TileShape &tileShape, 
    const LogicalTensorPtr &input) {
    
    // 1. 检查输入有效性
    CheckTensorShape(input, "YourOp");
    
    // 2. 推导输出Shape
    auto resultShape = YourOperationResultShape(input);
    
    // 3. 创建输出Tensor
    auto result = std::make_shared<LogicalTensor>(
        function, 
        input->Datatype(), 
        resultShape
    );
    
    // 4. 准备Tile信息
    TileInfo inputTileInfo(input->GetShape().size());
    TileInfo resultTileInfo(resultShape.size());
    
    LogicalInput logicalInput{input, inputTileInfo};
    
    // 5. 执行Tile切分
    TiledYourOperation<YourOpType::YOUR_OP_VARIANT1>(
        function, tileShape, 0, logicalInput, result, resultTileInfo
    );
    
    return result;
}
```

### 步骤3：实现TileOp定义

**文件**: `framework/src/interface/tileop/vector/your_op.h`

```cpp
#ifndef TILEOP_YOUR_OP_H
#define TILEOP_YOUR_OP_H

#include "pto_tile.h"
#include "utils/layout.h"
#include "utils/tile_tensor.h"

template <YourOp op, typename LastUse, typename T0, typename T1>
TILEOP void YourOpComputeImpl(T0 dst, T1 src) {
    constexpr auto n1 = Std::tuple_element<DIM_1ST, LastUse>::type::value;
    constexpr auto n2 = Std::tuple_element<DIM_2ND, LastUse>::type::value;
    constexpr auto n3 = Std::tuple_element<DIM_3RD, LastUse>::type::value;
    
    // 调用PTO指令
    if constexpr (op == YourOp::YOUR_OP_VARIANT1) {
        PTO_WITH_LAST_USE(pto::TYOUR_OP(dst, src), n1, n2, n3);
    }
    // ...
}

#endif // TILEOP_YOUR_OP_H
```

**说明**:
- TileOp层直接调用PTO指令（如pto::TADD, pto::TMUL等）
- PTO指令定义在pto-isa库中（`pto-isa/include/pto/npu/a5/`）
- LastUse用于内存优化，标记最后使用的Tile

#### 4.2 实现代码生成函数

```cpp
std::string CodeGenOpCloudNPU::PrintYourOpStatic(const PrintYourOpParam &param) const {
    const std::string &dstDtypeStr = param.dstDtypeStr;
    const std::string &srcDtypeStr = param.srcDtypeStr;
    const std::string &dVar = param.dVar;
    const std::string &sVar = param.sVar;
    
    // 1. 准备Shape参数
    std::vector<int64_t> os = NormalizeShape(originShape[ID1], SHAPE_DIM4);
    std::vector<int64_t> ds = NormalizeShape(rawShape[ID0], SHAPE_DIM4);
    std::vector<int64_t> s = NormalizeShape(rawShape[ID1], SHAPE_DIM4);
    
    // 2. 构建模板参数列表
    std::ostringstream os;
    std::vector<std::string> paramList;
    paramList.emplace_back(dstDtypeStr);
    paramList.emplace_back("/*OS*/");
    for (int i = 0; i < SHAPE_DIM4; ++i) {
        paramList.emplace_back(std::to_string(os[i]));
    }
    paramList.emplace_back("/*DS*/");
    for (int i = 0; i < SHAPE_DIM4; ++i) {
        paramList.emplace_back(std::to_string(ds[i]));
    }
    paramList.emplace_back("/*S*/");
    for (int i = 0; i < SHAPE_DIM4; ++i) {
        paramList.emplace_back(std::to_string(s[i]));
    }
    std::string templateParam = JoinString(paramList, CONN_COMMA);
    
    // 3. 构建函数调用参数
    paramList.clear();
    std::string dst = "(__ubuf__ " + dstDtypeStr + "*)" + dVar;
    std::string src = "(__ubuf__ " + srcDtypeStr + "*)" + sVar;
    paramList.emplace_back(dst);
    paramList.emplace_back(src);
    std::string tileOpCallParam = JoinString(paramList, CONN_COMMA);
    
    // 4. 生成TileOp调用代码
    os << tileOpName.c_str() << "_<" << templateParam << ">" 
       << "(" << tileOpCallParam << ");\n";
    
    return os.str();
}
```

**生成的代码示例**:
```cpp
YourOp_<float, /*OS*/1,1,1,16, /*DS*/1,1,1,16, /*S*/1,1,1,16>(
    (__ubuf__ float*)dst, 
    (__ubuf__ float*)src
);
```
