## 检测到的断裂点

### 🔴 致命断裂点 1: JIT Kernel 无法执行

| 属性 | 值 |
|------|-----|
| **类型** | A2 - API 行为不一致 |
| **优先级** | P0 (致命) |
| **实体** | pypto.frontend.jit |
| **置信度** | 高 |

**问题描述**:
调用 `@pypto.frontend.jit` 装饰的 kernel 函数时，内部 `pypto_impl.LaunchKernelTorch` 函数尝试访问 torch Tensor 的 `explicit_format` 属性，但该属性在标准 torch.Tensor 上不存在。

**触发条件**:
```python
@pypto.frontend.jit
def eq_kernel_2d(x1, x2, out):
    pypto.set_vec_tile_shapes(64, 128)
    out[:] = pypto.eq(x1, x2)

# 调用 kernel
eq_kernel_2d(torch_tensor_1, torch_tensor_2, output_tensor)  # 触发错误
```

**错误信息**:
```
AttributeError: 'Tensor' object has no attribute 'explicit_format'. Did you mean: 'explict_format'?
```

**根因归属**: framework
- 框架的 pypto_impl C++ 扩展期望 torch.Tensor 有 `explicit_format` 属性
- 标准 torch 2.6.0 的 Tensor 没有此属性
- 可能是 pypto 与特定 torch 版本绑定，或需要特殊的初始化步骤

**证据片段**:
```
File "/workspace/code/pypto/python/pypto/frontend/parser/entry.py", line 720, in _execute_kernel
    pypto_impl.LaunchKernelTorch(
AttributeError: 'Tensor' object has no attribute 'explicit_format'
```

**优化建议**:
1. 检查 pypto_impl 编译时的 torch 版本依赖
2. 文档中需要说明需要特定 torch 版本或补丁
3. 考虑在 pypto.frontend.jit 中添加 torch tensor 属性兼容性检查
