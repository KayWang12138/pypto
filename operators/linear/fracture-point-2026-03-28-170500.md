## 致命断裂点 (共 1 个)

### FP-001: matmul API 维度一致性约束未明确文档化
**类型**: A1 - API/框架类
**优先级**: P0 - 致命
**置信度**: high
**实体**:
- `pypto.matmul`

**问题描述**:
PyPTO 的 `matmul` API 要求两个输入张量的维度必须一致（都是 2D、都是 3D 或都是 4D），但在 linear 算子中，输入是 3D/4D 的 `[batch, seq, in_features]` 或 `[batch, heads, seq, in_features]`，而权重是 2D 的 `[out_features, in_features]`。这导致无法直接调用 matmul 进行 3D/4D 输入与 2D 权重的矩阵乘法。

**证据片段**:
1. 错误信息:
```
RuntimeError: Tensor dimension mismatch. Expect input_dim == mat2_dim and both in [2, 3, 4], got input_dim: 3, mat2_dim: 2.
```
2. API 报告中的约束描述
`api_report.md` 第 87 行:
```
| weight shape | 与 input 维度一致 | ✓ |
```
这个描述暗示了维度需要一致,但实际上并未明确说明"一致性"的含义是"维度相同"。
3. 设计文档中的描述
`design.md` 第 84 行:
```
| 1 | input @ weight^T | `pypto.matmul` | `a=input, b=weight, dtype=DT_FP32, b_trans=True` | docs/api/operation/pypto-matmul.md |
```
这个映射假设了可以直接将 3D input 与 2D weight 进行 matmul，但实际不支持。

**根因归属**:
- **维度 1 - 框架限制**: PyPTO matmul API 的实现确实要求输入维度一致
- **维度 2 - 文档缺陷**: `api_report.md` 和 `design.md` 都没有明确说明这个限制
**建议 Issue**:
- **标题**: [Doc] matmul API 维度一致性约束未明确文档化
- **类型**: Documentation
- **描述**:
  - **背景**: 在 linear 算子开发过程中，尝试使用 `pypto.matmul` 对 3D/4D 输入与 2D 权重进行矩阵乘法
  - **问题**: `matmul` API 要求 `input_dim == mat2_dim`，即两个输入张量的维度必须相同
  - **文档缺陷**:
    1. `docs/api/operation/pypto-matmul.md` 未明确说明"两个输入必须维度相同"这一限制
    2. `docs/tutorials/` 中的示例也没有展示这种混合维度场景
  - **建议**:
    1. 在 `pypto-matmul.md` 中增加"约束"章节,明确说明:
       - `matmul(a, b)` 要求 `a.ndim == b.ndim`
       - 两个输入张量必须都是 2D、3D 或 4D
       - 对于混合维度场景（如 3D input + 2D weight），需要先 reshape 到相同维度
    2. 提供最佳实践示例,展示如何处理 linear 层（3D/4D input + 2D weight）
    3. 在 `pypto-api-explorer` skill 中增加对此约束的检查逻辑

  - **影响范围**: 所有涉及 matmul 的算子开发
  - **优先级**: High
