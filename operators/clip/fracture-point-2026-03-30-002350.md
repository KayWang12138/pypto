## 4. 实体级断裂点详情

### 4.1 [FP-001] A2-API行为不一致: pypto.set_vec_tile_shapes

- **类型**: A2-API行为不一致
- **优先级**: 高
- **根因归属**: 框架
- **Issue 类型**: Bug Report
- **建议 Issue 标题**: `[Bug] pypto.set_vec_tile_shapes 不自动适配 tensor 维度导致编译失败`
- **置信度**: high
- **可能关联**: FP-002

#### 问题描述

`pypto.set_vec_tile_shapes()` 的 tiling 配置不会自动适配输入 tensor 的维度。当使用 2D tiling 配置处理 3D 或 4D tensor 时，会导致编译失败（"Run pass failed"）。

#### 证据片段

```
# 2D kernel with 2D tiling - PASS
pypto.set_vec_tile_shapes(64, 128)
# 3D input (4, 64, 128) -> PASS

# 4D kernel with 2D tiling - FAIL
pypto.set_vec_tile_shapes(64, 128)
# 4D input (2, 4, 64, 128) -> Run pass failed

# 4D kernel with 4D tiling - FAIL
pypto.set_vec_tile_shapes(4, 16, 64, 128)
# 4D input (2, 4, 64, 128) -> Run pass failed

错误输出:
[1m[95mINTERNAL BUG[0m [1m/workspace/code/pypto/operators/clip/clip_impl.py:1:0:[0m Errcode: FFFFFF!
Run pass failed., func CompileFunction, file host_machine.cpp, line 179
```

#### 复现步骤

1. 创建使用 `pypto.set_vec_tile_shapes(64, 128)` 的 kernel
2. 传入 4D tensor (如 [2, 4, 64, 128])
3. 观察编译失败

#### 期望行为

tiling 配置应自动适配 tensor 维度，或在文档中明确说明维度必须匹配。

#### 实际行为

使用与 tensor 维度不匹配的 tiling 配置会导致编译失败，错误信息不明确。

#### 优化建议

1. API 层面：`set_vec_tile_shapes` 应支持自动推断或更灵活的维度适配
2. 文档层面：在 `docs/api/` 中明确说明 tiling 配置必须与 tensor 维度匹配
3. 错误信息：提供更明确的错误提示，指出 tiling 配置与 tensor 维度不匹配

### 4.2 [FP-002] D1-文档缺失: pypto.set_vec_tile_shapes 维度要求

- **类型**: D1-文档缺失
- **优先级**: 高
- **根因归属**: 两者
- **Issue 类型**: Documentation
- **建议 Issue 标题**: `[Doc] pypto.set_vec_tile_shapes 缺少维度匹配要求说明`
- **置信度**: high
- **可能关联**: FP-001

#### 问题描述

`pypto.set_vec_tile_shapes()` 的文档未明确说明 tiling 配置的参数数量必须与输入 tensor 的维度匹配，也未提供处理不同维度 tensor 的推荐方法。

#### 证据片段

```
# 开发过程中尝试了多种 tiling 配置：
pypto.set_vec_tile_shapes(64, 128)      # 2D - 对 2D/3D 有效，对 4D 失败
pypto.set_vec_tile_shapes(8, 64, 128)   # 3D - 对 3D 有效
pypto.set_vec_tile_shapes(4, 16, 64, 128) # 4D - 仍然失败

# 最终解决方案：统一 reshape 为 2D
if ndim != 2:
    x = x.reshape(-1, x.shape[-1])
```

#### 期望行为

文档应明确说明：
1. tiling 配置参数数量与 tensor 维度的关系
2. 推荐的多维度 tensor 处理方法（如统一 reshape）
3. 不同维度 tiling 的适用场景

#### 实际行为

文档未提供这些关键信息，开发者需要通过反复试错才能找到正确的配置方式。

#### 优化建议

1. 在 `docs/api/` 中添加 tiling 配置与 tensor 维度的关系说明
2. 在 `references/execution-constraints.md` 中添加多维度 tensor 处理最佳实践
3. 在 `references/impl-template.py` 中展示 reshape 为统一维度的示例
