### 5.1 [FP-001] D3-文档误导: pypto.reshape

- **类型**: D3-文档误导
- **优先级**: 致命
- **根因归属**: 文档
- **Issue 类型**: Bug Report
- **建议 Issue 标题**: `[Doc] pypto.reshape 文档与实际行为不一致`
- **置信度**: 高
- **可能关联**: FP-002

#### 问题描述

`pypto.reshape` API 文档说明 reshape 是 view 操作，不涉及数据搬运或计算。设计文档和示例中暗示 reshape 不需要设置 TileShape。

然而，在实际运行中，当使用 `pypto.reshape` 时,如果没有调用 `pypto.set_vec_tile_shapes`,会报错:
```
op [REGISTER_COPY]tile shape not set, func Operation, file operation.cpp, line 184
```

这与文档描述严重不一致,导致开发者按照文档编写代码后无法运行。

#### 证据片段

```
# 文档描述 (docs/api/operation/pypto-reshape.md)
reshape 是纯 shape 变换操作，不涉及数据搬运或计算。

# 实际错误
[ERROR] op [REGISTER_COPY]tile shape not set, func Operation, file operation.cpp, line 184
```

#### 复现步骤

1. 创建一个使用 `pypto.reshape` 的 JIT kernel
2. 不调用 `pypto.set_vec_tile_shapes`
3. 运行 kernel
4. 观察错误 "tile shape not set"

#### 期望行为

文档应明确说明 reshape 操作仍需要设置 TileShape,或者在框架层面自动处理 TileShape 设置。

#### 实际行为

按照文档编写代码后,运行时报 "tile shape not set" 错误,需要额外添加 `pypto.set_vec_tile_shapes` 调用。

#### 相关链接

- docs/api/operation/pypto-reshape.md

#### 优化建议

1. 在 `pypto.reshape` 文档中添加 TileShape 设置要求的明确说明
2. 在文档示例中添加 `pypto.set_vec_tile_shapes` 调用
3. 或者改进框架,使 reshape 操作自动处理 TileShape 设置

### 5.2 [FP-002] D2-文档不完整: pypto.frontend.jit

- **类型**: D2-文档不完整
- **优先级**: 致命
- **根因归属**: 文档
- **Issue 类型**: Bug Report
- **建议 Issue 标题**: `[Doc] pypto.frontend.jit 文档不完整：闭包变量作用域限制未说明`
- **置信度**: 高
- **可能关联**: FP-001

#### 问题描述

当使用工厂函数模式创建 JIT kernel 时,在工厂函数内部定义的局部变量无法在 `@pypto.frontend.jit` 装饰的函数签名中使用。

PyPTO JIT 装饰器在模块加载时解析函数签名中的类型注解。这意味着类型注解中引用的变量必须在函数定义时可直接解析,而不能是工厂函数内的局部变量。

例如,以下代码会报错 `NameError: name 'pypto_dtype' is not defined`:

```python
def create_kernel(input_shape, output_shape, torch_dtype):
    pypto_dtype = DTYPE_MAP.get(torch_dtype, pypto.DT_FP32)  # 局部变量

    @pypto.frontend.jit
    def kernel(
        x: pypto.Tensor(input_shape, pypto_dtype),  # pypto_dtype 在此处无法解析
        out: pypto.Tensor(output_shape, pypto_dtype),
    ):
        ...
```

这个重要的限制没有在任何文档中说明,导致开发者在使用工厂函数模式时遇到难以理解的错误。

#### 证据片段

```
# 错误信息
pypto.frontend.parser.error.RenderedParserError: NameError: name 'pypto_dtype' is not defined

# 代码尝试
@pypto.frontend.jit
def reshape_kernel(
    input_tensor: pypto.Tensor(input_shape, pypto_dtype),  # pypto_dtype 是工厂函数的局部变量
    output_tensor: pypto.Tensor(output_shape, pypto_dtype),
):
    ...
```

#### 复现步骤

1. 创建一个工厂函数,接收 shape 和 dtype 参数
2. 在工厂函数内定义 `pypto_dtype` 变量
3. 在 JIT kernel 的类型注解中使用 `pypto_dtype`
4. 调用工厂函数创建 kernel
5. 观察错误 `NameError: name 'pypto_dtype' is not defined`

#### 期望行为

文档应明确说明:
1. JIT 装饰器在模块加载时解析函数签名
2. 类型注解中只能使用全局变量或参数,不能使用闭包变量
3. 如何正确使用工厂函数模式创建动态 shape 的 kernel

#### 实际行为

文档没有说明这个限制,开发者需要通过反复试错才能发现问题。

#### 相关链接

- docs/api/pypto-frontend-jit.md

#### 优化建议

1. 在 `pypto.frontend.jit` 文档中添加"闭包变量作用域限制"章节
2. 提供正确使用工厂函数模式的示例代码
3. 在错误信息中提供更具体的提示,说明如何解决此类问题
