## 算子需求规范

### 1. 基础信息
- **算子名称**: reshape
- **算子分类**: tensor_manipulation
- **数学公式**: $y = \text{reshape}(x, \text{shape})$
- **功能描述**: 将输入张量变换为指定的形状，保持数据不变，仅改变维度视图。支持动态轴（batch、seq_len）和负维度自动推断。

### 2. 关键特性

| 特性 | 是否需要 | 置信度 | 实现说明 | 优先级 |
|------|----------|--------|----------|--------|
| 动态 Shape | ✓ 需要 | ✓ 高 | 支持 batch、seq_len 等动态轴 | P0 |
| 负维度推断 | ✓ 需要 | ✓ 高 | 支持 shape 中一个维度为 -1，自动推断 | P0 |
| 多种 dtype | ✓ 需要 | ✓ 高 | 支持 float32、bfloat16、float16 | P0 |
| 内存连续性 | ⚠ 待定 | ⚠ 中 | 可能需要 contiguous 处理 | P1 |

### 3. 算法描述

reshape 算子是简单的 shape 变换操作，不涉及复杂计算流程，无需算法描述。

### 4. 数据流图

```
        输入 x                  目标 shape            输出 y
    ┌──────────────┐       ┌──────────────┐      ┌──────────────┐
    │  [b, s1, d]  │       │   [s1,s2,s3]  │      │ [b, s2, s3]  │
    │   float32    │ ────▶ │    int32      │ ───▶ │   float32    │
    └──────────────┘       └──────────────┘      └──────────────┘

    动态轴: b, s1             (支持 -1)           动态轴: b, s2, s3

    约束: b × s1 × d = b × s2 × s3
```

### 5. 数据规格

**输入规格**:

| 变量 | Shape | Dtype | 动态轴 | 说明 |
|------|-------|-------|--------|------|
| x | [d1, d2, ..., dn] | float32/bfloat16/float16 | batch, seq_len | 输入张量，支持任意维度 |
| shape | [s1, s2, ..., sm] | int32 | 无 | 目标形状，支持一个维度为 -1 |

**输出规格**:

| 变量 | Shape | Dtype | 动态轴 | 说明 |
|------|-------|-------|--------|------|
| y | [s1, s2, ..., sm] | float32/bfloat16/float16 | 由 shape 决定 | 输出张量，形状为目标 shape |

### 6. 数据类型支持

| Dtype | 支持 | atol | rtol | 备注 |
|-------|------|------|------|------|
| float32 | ✓ | 0.001 | 0.001 | 默认精度 |
| bfloat16 | ✓ | 0.01 | 0.01 | 低精度模式 |
| float16 | ✓ | 0.01 | 0.01 | 低精度模式 |

### 7. 精度要求
- **atol**: 0.001 (float32) / 0.01 (bfloat16/float16)
- **rtol**: 0.001 (float32) / 0.01 (bfloat16/float16)

### 8. 动态轴说明
- **动态轴**: batch, seq_len
- **轴含义**:
  - batch: 批次大小，在推理时可能变化
  - seq_len: 序列长度，在推理时可能变化
- **取值范围**:
  - batch: [1, INT32_MAX]
  - seq_len: [1, INT32_MAX]

### 9. 边界条件处理
- **零值**: 正常处理
- **极值**: 正常处理
- **NaN/Inf**: 保持不变（reshape 不涉及计算）
- **shape 约束**:
  - shape 中最多一个维度为 -1
  - 元素总数必须匹配: ∏(d_i) = ∏(s_i)
  - 当 shape 包含 -1 时，自动推断该维度大小

### 10. 性能要求
- **性能目标**: reshape 通常是 view 操作，性能开销极小。对于需要内存拷贝的场景，要求性能不低于 PyTorch 实现。

### 11. 参考信息
- **参考实现**: PyTorch torch.reshape() / Tensor.view()
- **论文**: 无
- **类似算子**: view, flatten, squeeze, unsqueeze

### 12. 应用场景
- **目标模型**: Transformer、CNN、RNN 等各类模型
- **使用位置**:
  - Linear 层前后的 shape 变换
  - Attention 计算中的维度重排
  - 模型输入/输出的 shape 调整
