#### 问题描述

在实现 mean_reduction 算子时，按照 `@pypto.frontend.jit` 装饰器的常规用法编写 kernel 函数，将输入和输出 tensor 参数与非 tensor 参数 (dim, keepdim, reduce_size) 混合放置。

运行时报错：
```
[ERROR] Runtime error: Non-tensor parameters must come after all tensor parameters. Found tensor parameter 'output_tensor' after non-tensor parameter(s).
```

该约束虽然在 `references/execution-constraints.md` 中有提及 ("JIT 函数中张量参数在前，非张量参数在后")
但该文档是 skill 内部参考文档，不是面向用户的公开文档。

#### 证据片段

Session 原文:
```
[Case 1] dim=-1, keepdim=False
  Input shape : torch.Size([2, 4])

[ERROR] Runtime error: Non-tensor parameters must come after all tensor parameters. Found tensor parameter 'output_tensor' after non-tensor parameter(s).
```

#### 复现步骤

1. 创建一个使用 `@pypto.frontend.jit` 装饰的 kernel 函数
2. 将非 tensor 参数 (如 int, bool, float) 放在 tensor 参数之前或中间
3. 调用该 kernel 函数

#### 期望行为

- 方案 A: 编译时给出明确的错误提示，说明参数顺序约束
- 方案 B: 在公开文档中明确说明此约束

#### 实际行为

运行时才报错，且错误信息不够友好，需要开发者自行理解 "Non-tensor parameters must come after all tensor parameters" 的含义。

#### 相关链接

- `docs/api/pypto-frontend-jit.md` - 需要补充参数顺序约束
- `docs/tutorials/development/` - 需要在教程中强调此约束

#### 优化建议

1. **文档层面**: 在 `docs/api/pypto-frontend-jit.md` 中增加一个醒目的 "Note" 或 "Warning" 部分
   明确说明: "张量参数必须放在所有非张量参数之前"

2. **错误信息层面**: 改进错误信息，   指出具体哪个参数违反了约束
   例如: "Parameter 'output_tensor' (position 5) is a tensor but comes after non-tensor parameter 'dim' (position 2). All tensor parameters must come before non-tensor parameters."

3. **编译时检查**: 如果可能，在编译阶段就检查参数顺序
