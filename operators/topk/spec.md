## 算子需求规范

### 1. 基础信息
- **算子名称**: topk
- **算子分类**: selection
- **数学公式**: $\text{values}, \text{indices} = \text{topk}(\text{input}, k, \text{dim}, \text{largest}, \text{sorted})$
- **功能描述**: 返回输入张量在指定维度上最大（或最小）的 k 个元素及其索引。支持动态轴。

### 3. 算法描述

```
Algorithm: TopK Selection
────────────────────────────────────
输入: input [D0, D1, ..., D_dim, ..., Dn], k, dim, largest, sorted
输出: values [..., k, ...], indices [..., k, ...]

1. 计算实际维度索引: actual_dim = dim >= 0 ? dim : n + dim
2. 获取 dim 维度大小: dim_size = input.shape[actual_dim]
3. 验证: k <= dim_size, 否则报错
4. 对 dim 维度进行部分排序:
   4.1 若 largest=True: 找最大的 k 个元素
   4.2 若 largest=False: 找最小的 k 个元素
5. 若 sorted=True: 对选中的 k 个元素按值降序(largest)或升序(!largest)排列
6. 返回:
   - values: 选中元素组成的张量
   - indices: 选中元素在 dim 维度上的原始索引
```

- **动态轴**: b (batch), s (seq), n (num)
- **轴含义**:
  - b: batch 维度，批次大小
  - s: seq 维度，序列长度

  - d: 固定维度，隐藏层维度
- **取值范围**: [1, INT32_MAX]

### 9. 边界条件处理
- **零值**: 正常计算，零值可作为有效元素参与比较
- **极值**: 正常计算，支持 Inf/-Inf
- **NaN/Inf**: NaN 视为最大值（largest=True 时会被选中），Inf 正常参与比较
- **k 边界**: k > dim_size 时报错，k == dim_size 时返回全部元素
