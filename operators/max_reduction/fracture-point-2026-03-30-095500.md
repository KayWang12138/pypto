## 检测到的断裂点

### 1. pypto.max vs pypto.amax API 命名混淆 (D3 - 文档不完整)

| 属性 | 值 |
|------|-----|
| **类型** | D3 |
| **优先级** | P1 (高) |
| **实体** | pypto.max, pypto.amax |
| **根因归属** | framework |
| **置信度** | high |

**问题描述**:
开发者误用 `pypto.max(input, dim, keepdim)` 进行归约操作，但正确的 API 是 `pypto.amax`。
- `pypto.max` 在 PyPTO 中可能是元素级最大值（类似 `torch.maximum`）
- `pypto.amax` 才是归约操作（类似 `torch.amax`）

**错误信息**:
```
TypeError: max() got an unexpected keyword argument 'dim'
```

**解决方案**:
使用正确的 API:
```python
# 错误
result = pypto.max(input_tensor, dim=dim, keepdim=keepdim)

# 正确
result = pypto.amax(input_tensor, dim, keepdim)
```

**建议**:
在文档中明确区分 `pypto.maximum`、`pypto.max`、`pypto.amax` 的用途。
