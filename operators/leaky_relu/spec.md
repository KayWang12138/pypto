# LeakyReLU 算子需求规范

## 1. 基础信息

| 属性 | 值 |
|------|-----|
| **算子名称** | leaky_relu |
| **算子分类** | activation |
| **数学公式** | y = x if x ≥ 0 else α·x |
| **功能描述** | 带泄露的 ReLU 激活函数，负区间保持小梯度 |

## 2. 关键特性

| 特性 | 是否需要 | 置信度 | 实现说明 | 优先级 |
|------|----------|--------|----------|--------|
| 动态轴支持 | ✓ 需要 | ✓ 高 | 使用 pypto.Tensor([], DT_FP32) 隐式推断 | P0 |
| 多维输入处理 | ✓ 需要 | ✓ 高 | 1D-4D 输入 reshape 到 2D 处理 | P0 |
| FP16 支持 | ✓ 需要 | ✓ 高 | 类型转换后计算 | P1 |

## 3. 数据流图

```
    输入 x                    输出 y
+--------------+         +--------------+
|  [*, D]      |         |  [*, D]      |
|   float32    |  ---->  |   float32    |
+--------------+ leaky   +--------------+
                 α=0.01

公式: y = x if x >= 0 else α * x
动态轴: 支持任意维度
```

## 4. 数据规格

| 变量 | Shape | Dtype | 动态轴 | 说明 |
|------|-------|-------|--------|------|
| x | [*, D] | float32 | 所有维度 | 输入张量 |
| y | [*, D] | float32 | 所有维度 | 输出张量 |
| alpha | scalar | float | - | 负区间斜率，默认 0.01 |

## 5. 精度要求

- **atol**: 1e-5
- **rtol**: 1e-5

## 6. 参考信息

- **PyTorch API**: `torch.nn.functional.leaky_relu(x, negative_slope=alpha)`
- **数学等价**: `torch.where(x >= 0, x, alpha * x)`
