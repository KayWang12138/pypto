## 检测到的断裂点

### 1. pypto.where + pypto.ge 组合编译失败 (A1 - API 约束)

| 属性 | 值 |
|------|-----|
| **类型** | A1 |
| **优先级** | P0 (致命) |
| **实体** | pypto.where, pypto.ge |
| **根因归属** | framework |
| **置信度** | high |

**问题描述**:
使用 `pypto.where(pypto.ge(x, 0), x, alpha*x)` 实现 LeakyReLU 会导致 C++ 编译失败。

**错误信息**:
```
error: no member named 'Wait' in 'pto::Tile<...>'
TCompare<5, 0, float>(ubTensor_2, ubTensor_0, ubTensor_3, 0);
```

**解决方案**:
使用数学等价公式: `leaky_relu(x) = max(x, alpha*x)`
```python
neg_val = pypto.mul(x, alpha)
result = pypto.maximum(x, neg_val)
```

### 2. pypto.mul 标量参数顺序 (A2 - API 约束)

| 属性 | 值 |
|------|-----|
| **类型** | A2 |
| **优先级** | P1 (高) |
| **实体** | pypto.mul |
| **根因归属** | framework |
| **置信度** | high |

**问题描述**:
`pypto.mul(scalar, tensor)` 不支持，必须是 `pypto.mul(tensor, scalar)`。

**错误信息**:
```
TypeError: Mul(): incompatible function arguments
Invoked with: 0.01, <pypto.pypto_impl.Tensor object>
```

**正确用法**:
```python
# 错误
neg_val = pypto.mul(alpha, x)

# 正确
neg_val = pypto.mul(x, alpha)
```
