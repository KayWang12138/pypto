### FP-1: pypto.frontend.jit 訡块路径错误 (致命)

**优先级**: 致命
**置信度**: 高
**根因**: framework
**触发次数**: 1

**问题描述**:
在实现 `exp_impl.py` 时，使用 `@pypto.frontend.jit` 装饰器报错:
```
AttributeError: module 'pypto' has no attribute 'frontend'
```
原始代码尝试 `import pypto.frontend` 或 `from pypto.frontend import jit`，但 pypto 包的 frontend 模块不是顶层模块,需要通过 `import pypto` 后访问 `pypto.frontend.jit`。

**证据片段**:
```
> File "/workspace/code/pypto/operators/exp/exp_impl.py", line 40, in <module>
    @pypto.frontend.jit
AttributeError: module 'pypto' has no attribute 'frontend'
```
**实际修复**:
查看 `operators/sigmoid/sigmoid_impl.py` 的参考实现也使用了 `@pypto.frontend.jit`，说明这是正确的 API 路径。 问题在于当前环境安装的 pypto 包可能是旧版本或构建不完整。
**根因分析**:
1. `pypto` 包的 `frontend` 子模块需要从 C 扩展正确编译才能访问
2. 安装的 pypto 包可能是通过 `pip install -e .` 安装的本地开发版本
3. 运行时 `import pypto` 成功,但 `pypto.frontend` 不可访问

**优化建议**:
1. **文档层面**: 在 `docs/api/config/pypto-frontend-jit.md` 或相关文档中明确说明 `pypto.frontend` 的正确导入方式和依赖要求
2. **构建层面**: 检查 pypto 包的构建流程,确保 `frontend` 模块被正确编译和导出
3. **安装层面**: 提供更清晰的安装验证步骤,让用户确认 pypto.frontend 可用

### FP-2: PYTHONPATH 配置问题 (高)
**优先级**: 高
**置信度**: 高
**根因**: environment
**触发次数**: 1

**问题描述**:
直接运行 `python test_exp.py` 时报错 `ModuleNotFoundError: No module named 'pypto'`。需要设置 `PYTHONPATH=/workspace/code/pypto/python` 才能正确导入 pypto。
**证据片段**:
```

```
**根因分析**:
1. pypto 包在 `/workspace/code/pypto/python/` 目录下,不在默认 Python 路径中

**优化建议**:

3. 在 test 脚本中添加 PYTHONPATH 检查和提示
