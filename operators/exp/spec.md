### 1. 基础信息
- **算子名称**: exp
- **算子分类**: element-wise

### 3. 算法描述
<!-- 简单 element-wise 算子，公式已足够描述计算逻辑 -->

```
Algorithm: Exp (Element-wise)
────────────────────────────────────
输入: x ∈ R^{shape}, dtype=FP32/FP16
输出: y ∈ R^{shape}, dtype=与输入相同

1. 如果输入是 4D 张量 [b, s, n, d]:
     1.1 reshape 为 2D: x_2d = x.reshape(-1, d)
2. 对每个元素 i: y[i] = exp(x[i])
3. 如果执行了 reshape:
     3.1 恢复原始 shape: y = y_2d.reshape(original_shape)
4. return y
```
