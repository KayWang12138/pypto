## 算子需求规范

### 1. 基础信息
- **算子名称**: concat
- **算子分类**: tensor_manipulation
- **数学公式**: 沿指定维度拼接多个张量，保持其他维度不变
- **功能描述**: 将多个张量沿指定维度拼接成一个张量。所有输入张量在非拼接维度上的 shape 必须相同，dtype 必须一致。

### 3. 算法描述

```
Algorithm: Tensor Concatenation
────────────────────────────────────
输入: tensors = [T₀, T₁, ..., T_{N-1}], dim
输出: output Tensor

1. 检查所有张量的数量 N >= 2
2. 检查所有张量的 dtype 一致
3. 标准化 dim 参数（处理负数索引）
4. 检查所有张量的维度数相同
5. 检查所有张量在非 dim 维度的 shape 相同
6. 计算输出 shape：
   output_shape[dim] = sum(T_i.shape[dim] for all i)
   output_shape[other] = T_0.shape[other]
7. 分配输出张量内存
8. 沿 dim 维度依次复制各输入张量数据到输出张量
9. return output
```

```
约束条件：
  • 非拼接维度必须相同：所有 tensor 的 b、s 必须一致

```

### 8. 动态轴说明
- **动态轴**: batch (b), seq_len (s)
- **轴含义**:
  - batch: 批次大小，表示一次处理的样本数量
  - seq_len: 序列长度，表示序列数据的时间步数
- **取值范围**:
  - batch: [1, 65536]
  - seq_len: [1, 32768]
  - 特征维度 d_i: [1, 16384]

### 9. 边界条件处理
- **零值**: 正常计算，零值作为有效数据参与拼接
- **极值**: 正常计算，保持数值不变
- **NaN/Inf**: 正常计算，保持数值不变（不做特殊处理）
- **空张量**: 当某个输入张量在 dim 维度大小为 0 时，跳过该张量
- **单张量输入**: 返回该张量的副本（虽然要求至少2个，但需处理边界情况）
