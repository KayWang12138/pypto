## 检测到的断裂点

### 🔴 致命断裂点 1: JIT Kernel 无法执行 - 框架级兼容性问题

| 属性 | 值 |
|------|-----|
| **类型** | A2 - API 行为不一致 |
| **优先级** | P0 (致命) |
| **实体** | pypto.frontend.jit / pypto_impl.LaunchKernelTorch |
| **置信度** | 高 |

**问题描述**:
调用任何 `@pypto.frontend.jit` 装饰的 kernel 函数时，内部 `pypto_impl.LaunchKernelTorch` 函数尝试访问 torch Tensor 的 `explicit_format` 属性，但该属性在标准 torch.Tensor 上不存在。错误信息提示可能是拼写错误 `explict_format`。

**影响范围**:
- **所有** 使用 JIT decorator 的算子都无法执行
- 包括: gelu, eq, add, mul 等所有算子
- 这是一个框架级的兼容性问题

**触发条件**:
```python
@pypto.frontend.jit
def any_kernel(x, out):
    pypto.set_vec_tile_shapes(...)
    out[:] = pypto.op(x)

any_kernel(torch_tensor, output_tensor)  # 触发错误
```

**错误信息**:
```
AttributeError: 'Tensor' object has no attribute 'explicit_format'. Did you mean: 'explict_format'?
```

**根因归属**: framework
- 框架的 pypto_impl C++ 扩展期望 torch.Tensor 有 `explicit_format` 属性
- 标准 torch 2.6.0 的 Tensor 没有此属性
- 可能是 pypto 与特定 torch 版本绑定，或需要特殊的初始化步骤
- 错误提示 "Did you mean: 'explict_format'" 暗示可能存在拼写不一致

**证据片段**:
```
File "/workspace/code/pypto/python/pypto/frontend/parser/entry.py", line 720, in _execute_kernel
    pypto_impl.LaunchKernelTorch(
AttributeError: 'Tensor' object has no attribute 'explicit_format'. Did you mean: 'explict_format'?
```

**验证测试**:
```python
>>> import torch
>>> t = torch.randn(4)
>>> hasattr(t, 'explicit_format')
False
>>> hasattr(t, 'explict_format')
False
```

**优化建议**:
1. **紧急**: 检查 pypto_impl 编译时的 torch 版本依赖，确保与当前 torch 2.6.0 兼容
2. 检查是否需要在 torch tensor 上添加 `explicit_format` 属性的初始化代码
3. 修正可能的拼写问题: `explicit_format` vs `explict_format`
4. 在文档中说明需要特定 torch 版本或补丁

## 实现说明

**公式**: `GELU(x) = x * Φ(x)` where `Φ(x)` is the CDF of standard normal distribution

**API 映射**:
- 无直接 `pypto.gelu()` API
- 使用 tanh 近似公式: `0.5 * x * (1 + tanh(sqrt(2/π) * (x + 0.044715 * x^3)))`

**动态轴支持**:
- 使用 `pypto.Tensor([], pypto.DT_FP32)` 隐式推断
