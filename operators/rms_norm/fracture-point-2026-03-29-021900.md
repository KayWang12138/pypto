## 3. 致命断裂点 (P0)

### 3.1 [A2] pypto.assemble 对多维 tensor 的 offset 维度限制未明确

**优先级**: P0 (致命)
**根因归属**: framework
**置信度**: 高

#### 问题描述

`pypto.assemble` API 要求 offset 的维度必须与 output tensor 的维度完全匹配。对于 2D tensor `[32, 128]`，使用 `[0, 0]` 可以通过；但对于 3D tensor `[2, 128, 4096]`，需要使用 `[0, 0, 0]`。

文档中没有明确说明这一限制，导致开发者在处理多维 tensor 时遇到编译失败。错误信息 "dest.GetShape().size() == dynOffset.size()" 虽然明确，但没有给出修复建议。

#### 证据片段

```
ERROR:root:Record function rms_norm_kernel failed: RuntimeError: CHECK FAILED: dest.GetShape().size() == dynOffset.size()
location: ??:0:0
Assemble: dynOffset and dest requires same shape, func Assemble, file operation_impl.cpp, line 1022
```

测试结果：
- Level 0 (2D tensor [32, 128]): **通过**
- Level 1 (3D tensor [2, 128, 4096]): **失败**

#### 触发信号

| 信号类型 | 触发次数 | 阈值 | 说明 |
|---------|---------|------|------|
| 操作失败 | 4+ | ≥1 | 多次编译失败 |
| 错误信息明确 | 1 | ≥1 | 错误信息清晰但缺乏修复指导 |

#### 影响范围

- **直接影响**: 无法使用 `pypto.assemble` 处理 3D+ tensor
- **间接影响**: 所有需要多维 tensor 输出的算子开发受阻
- **关联断裂点**: 与 D2 (pypto.rms_norm 文档不足) 关联

#### Issue 建议

**类型**: Bug Report
**标题**: "[API] pypto.assemble 对多维 tensor 的 offset 维度限制未在文档中明确说明"

**描述建议**:
```
## 问题描述
pypto.assemble API 要求 offset 参数的维度必须与 output tensor 维度匹配，但文档未说明此限制。

## 复现步骤
1. 创建 3D tensor [b, s, d] 的输出
2. 使用 pypto.assemble(result, [0, 0], output)
3. 编译失败："dest.GetShape().size() == dynOffset.size()"

## 期望行为
文档应明确说明 offset 维度要求，或在错误信息中提示正确用法。

## 建议修复
1. 更新 docs/api/operation/pypto-assemble.md，明确 offset 维度要求
2. 改进错误信息："offset dimension (2) must match output tensor dimension (3)"
3. 添加多维 tensor 使用示例
```

#### 优化建议

1. **文档改进**:
   - 在 `docs/api/operation/pypto-assemble.md` 中添加 offset 维度要求的明确说明
   - 添加多维 tensor 示例：`pypto.assemble(result, [0, 0, 0], output_3d)`

2. **错误信息改进**:
   ```cpp
   // 当前: "dest.GetShape().size() == dynOffset.size()"
   // 建议: "offset dimension ({}) must match output tensor dimension ({}). Expected: [0, 0, ...] with {} elements"
   ```

3. **API 增强** (可选):
   - 考虑支持自动推断 offset，如 `pypto.assemble(result, output)` 默认使用全零 offset

**优先级**: P1 (高)
**根因归属**: framework
**置信度**: 中

#### 问题描述

`pypto.rms_norm` API 文档只提供了简单的 2D tensor 示例，没有展示如何在 JIT kernel 中正确使用，包括：
- tiling 配置 (`pypto.set_vec_tile_shapes`)
- assemble 操作 (`pypto.assemble`)
- 完整的 kernel 函数结构

开发者需要查看 `examples/02_intermediate/basic_nn/layer_normalization/layer_norm.py` 才能理解完整用法。

#### 证据片段

文档中的示例：
```python
x = pypto.tensor([2, 4], pypto.DT_FP32)
gamma = pypto.tensor([4], pypto.DT_FP32)
y = pypto.rms_norm(x, gamma)
```

这个示例：
- 不涉及 JIT kernel
- 不展示 tiling 配置
- 不展示 assemble 操作
- 不展示与 torch.Tensor 的集成

#### 优化建议

1. **文档增强**:
   ```python
   # 建议在 docs/api/operation/pypto-rms_norm.md 添加：

   @pypto.frontend.jit
   def rms_norm_kernel(
       x: pypto.Tensor(),
       gamma: pypto.Tensor(),
       output: pypto.Tensor(),
       eps: float = 1e-6,
   ):
       pypto.set_vec_tile_shapes(64, 128)
       result = pypto.rms_norm(x, gamma, eps)
       pypto.assemble(result, [0, 0], output)

   def rms_norm_wrapper(x: torch.Tensor, gamma: torch.Tensor) -> torch.Tensor:
       output = torch.empty_like(x)
       rms_norm_kernel(x, gamma, output)
       return output
   ```
