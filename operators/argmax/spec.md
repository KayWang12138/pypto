# argmax 算子规格文档

## 基本信息

| 字段 | 值 |
|------|-----|
| 算子名称 | argmax |
| 分类 | reduction |
| 复杂度 | medium |
| 参考实现 | torch.argmax(input, dim=None, keepdim=False) |

## 数学公式

```
argmax(x, dim) = argmax_i x[..., i, ...]

当 dim=None 时:
argmax(x) = argmax_i x.flatten()[i]
```

**语义**：沿指定维度找最大值的索引。如果有多个最大值，返回第一个的索引。

## 数据流图

```
                    输入 x
              ┌──────────────────┐
              │ [b, s, n, d]     │
              │ float32/float16  │
              └────────┬─────────┘
                       │
                       ▼
              ┌──────────────────┐
              │  沿 dim 维度找    │
              │  最大值索引       │
              └────────┬─────────┘
                       │
                       ▼
                    输出 y
              ┌──────────────────┐
              │ [b, s, n]        │  (dim=3, keepdim=False)
              │ int64            │
              └──────────────────┘

动态轴: b (batch), s (sequence)
```

## 输入输出规格

### 输入

| 名称 | Shape | Dtype | 动态轴 | 描述 |
|------|-------|-------|--------|------|
| x | [b, s, n, d] | float32, float16 | b, s | 输入张量 |
| dim | scalar | int | - | 沿哪个维度计算，支持 None 表示展平后计算 |

### 输出

| 名称 | Shape | Dtype | 动态轴 | 描述 |
|------|-------|-------|--------|------|
| y | 由 dim 和 keepdim 决定 | int64 | b, s (当 dim > 1) | 最大值索引 |

**Shape 规则**：
- 当 `keepdim=True`: 输出 shape 与输入相同，但 dim 维度 size=1
- 当 `keepdim=False`: 输出 shape 移除 dim 维度
- 当 `dim=None`: 输出为标量

## 可选参数

| 参数 | 类型 | 默认值 | 优先级 | 实现复杂度 | 描述 |
|------|------|--------|--------|------------|------|
| dim | int or None | None | P0 | 中 | 沿哪个维度计算，None 时展平后计算 |
| keepdim | bool | False | P1 | 低 | 是否保持维度 |

### 可选参数分析

#### dim=None

- **代码位置**: 预处理阶段
- **计算逻辑**: 将输入张量展平为一维，然后计算全局最大值索引
- **实现复杂度**: 中 - 需要额外的展平逻辑，PyPTO 需要特殊处理
- **依赖关系**: 独立

#### keepdim

- **代码位置**: 后处理阶段
- **计算逻辑**: 在输出 shape 中保留 dim 维度，size 设为 1
- **实现复杂度**: 低 - PyPTO 直接支持 reshape
- **依赖关系**: 依赖 dim 参数

## 精度要求

| 配置 | atol | rtol |
|------|------|------|
| float32 | 0.001 | 0.001 |
| float16 | 0.001 | 0.001 |

**注意**: argmax 输出为整数索引，精度验证使用精确匹配。

## 动态轴

| 轴名称 | 含义 | 范围 | 说明 |
|--------|------|------|------|
| b | batch | [1, INT32_MAX] | 批次维度，支持动态 |
| s | sequence | [1, INT32_MAX] | 序列维度，支持动态 |

## 边界条件处理

| 条件 | 处理方式 |
|------|----------|
| 多个最大值 | 返回第一个最大值的索引 |
| 空张量 | 未定义行为（输入约束：dim 维度 size > 0） |
| NaN | NaN 被视为最大值（遵循 PyTorch 行为） |
| Inf | 正/负 Inf 正常参与比较 |

## 性能目标

- 基准: 首跑精度成功性能的 2 倍
- 优化方向: 减少内存访问，利用 NPU 并行能力

| 配置名称 | 类型 | 优先级 | 参数 | 输入 Shape | 输出 Shape | 说明 |

## 实现约束

1. **动态轴支持**: 必须支持 b 和 s 维度为动态
2. **数据类型**: 优先支持 float32 和 float16
3. **输出类型**: 必须为 int64
4. **多最大值**: 返回第一个最大值索引
