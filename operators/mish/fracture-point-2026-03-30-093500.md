## 检测到的断裂点

### 1. PyPTO 缺少 tanh API (D1 - 文档缺失/API 不存在)

| 属性 | 值 |
|------|-----|
| **类型** | D1 |
| **优先级** | P1 (高) |
| **实体** | pypto.tanh |
| **根因归属** | framework |
| **置信度** | high |

**问题描述**:
Mish 公式需要 `tanh(softplus(x))`，但 PyPTO 框架没有提供 `pypto.tanh` API。

**证据**:
- 搜索 `pypto.tanh` 在 docs/ 和 examples/ 中无结果
- gelu 示例使用 `tanh(x) = 2 * sigmoid(2x) - 1` 近似

**优化建议**:
在 PyPTO 中添加 `pypto.tanh` API，或文档化 tanh 近似方案。

---

### 2. 3D+ Tiling 编译失败 (A1 - API 约束)

| 属性 | 值 |
|------|-----|
| **类型** | A1 |
| **优先级** | P0 (致命) |
| **实体** | pypto.set_vec_tile_shapes |
| **根因归属** | framework |
| **置信度** | high |

**问题描述**:
使用 `set_vec_tile_shapes(64, 128)` 处理 3D/4D 输入会导致编译失败："Run pass failed"。

**证据**:
- 3D 输入 `[2, 128, 1024]` 直接调用 kernel 报错
- 错误信息: `Errcode: FFFFFF! Run pass failed., func CompileFunction`

**解决方案**:
将 3D+ 输入 reshape 为 2D 后再调用 kernel，完成后 reshape 回原 shape。
