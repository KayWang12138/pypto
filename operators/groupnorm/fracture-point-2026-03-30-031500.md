### 1. 大 K 值 tiling 编译失败 (A1 - API 约束)

| 属性 | 值 |
|------|-----|
| **类型** | A1 |
| **优先级** | P0 (致命) |
| **实体** | pypto.set_vec_tile_shapes |
| **根因归属** | framework |
| **置信度** | high |

**问题描述**:
当 K 值较大时 (如 K=392 = 2*14*14)，使用 `pypto.set_vec_tile_shapes(64, K)` 会导致编译失败。

**错误信息**:
```
Errcode: FFFFFF!
Run pass failed., func CompileFunction, file host_machine.cpp, line 179
```

**复现条件**:
- 输入 shape: [2, 64, 14, 14]
- num_groups: 32
- K = C//G * H * W = 2 * 14 * 14 = 392

**通过的配置**:
- 输入 shape: [2, 32, 8, 8], num_groups: 8, K = 4 * 8 * 8 = 256

**建议**:
- 需要框架层面优化大 K 值的 tiling 策略
- 或提供更灵活的 tiling 配置选项

## 实现说明

GroupNorm 实现采用 reshape + sum 归约方式:
1. 将 [N, C, H, W] reshape 为 [N*G, C//G*H*W]
2. 沿 dim=1 计算均值和方差
3. 归一化
4. Reshape 回原始 shape
5. 应用 affine 变换

该方案在小规模配置下可工作，但大规模配置受限于 tiling 编译问题。
