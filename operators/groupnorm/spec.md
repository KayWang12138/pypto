# GroupNorm 算子需求规范

## 1. 基础信息

| 属性 | 值 |
|------|-----|
| **算子名称** | groupnorm |
| **算子分类** | normalization |
| **数学公式** | y = γ * (x - μ) / σ + β |
| **功能描述** | 将输入张量按组进行归一化处理 |

## 2. 关键特性

## 3. 数据流图

```
    输入 x [N, C, H, W]          weight γ [C]          bias β [C]
           │                          │                      │
           │                          │                      │
           ▼                          ▼                      ▼
    ┌──────────────────────────────────────────────────────────┐
    │                    GroupNorm (G groups)                  │
    │  1. Reshape: [N, G, C//G, H, W]                         │
    │  2. Compute μ, σ per group                              │
    │  3. Normalize: (x - μ) / σ                             │
    │  4. Reshape back: [N, C, H, W]                         │
    │  5. Affine: γ * x + β                                  │
    └──────────────────────────────────────────────────────────┘
                              │
                              ▼
                    输出 y [N, C, H, W]
```

## 4. 数据规格

| 变量 | Shape | Dtype | 动态轴 | 说明 |
|------|-------|-------|--------|------|
| x | [N, C, H, W] | float32 | N, H, W | 输入张量 |
| weight | [C] | float32 | - | 缩放参数 |
| bias | [C] | float32 | - | 偏移参数 |
| y | [N, C, H, W] | float32 | N, H, W | 输出张量 |

## 5. 参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| num_groups | int | 分组数 G |
| num_channels | int | 通道数 C |
| eps | float | 数值稳定性常数，默认 1e-5 |

## 6. 精度要求

- **atol**: 1e-4
- **rtol**: 1e-4

## 7. 参考信息

- **PyTorch API**: `torch.nn.functional.group_norm(x, num_groups, weight, bias, eps)`
