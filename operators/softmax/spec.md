## 算子需求规范

### 1. 基础信息
- **算子名称**: softmax
- **算子分类**: normalization
- **数学公式**: $\text{softmax}(x_i) = \frac{\exp(x_i - \max(x))}{\sum_j \exp(x_j - \max(x))}$
- **功能描述**: 对输入张量沿指定轴进行 softmax 归一化，输出概率分布。使用数值稳定实现（减去最大值）。

### 2. 关键特性

| 特性 | 是否需要 | 置信度 | 实现说明 | 优先级 |
|------|----------|--------|----------|--------|
| 数值稳定性 (safe_softmax) | ✓ 需要 | ✓ 高 | 减去最大值避免 exp 溢出 | P0 |
| 指定轴计算 (dim参数) | ✓ 需要 | ✓ 高 | 沿指定轴进行归一化 | P0 |
| 多轴支持 | ✗ 不需要 | ⚠ 中 | 暂不支持多轴同时归一化 | P3 |

### 3. 算法描述

```
Algorithm: Safe Softmax
────────────────────────────────────
输入: x ∈ R^{d_1 × d_2 × ... × d_n}, 归一化轴 dim
输出: y ∈ R^{d_1 × d_2 × ... × d_n}

1. max_val = max(x, axis=dim, keepdims=True)  // 沿指定轴求最大值
2. x_shifted = x - max_val                     // 数值稳定：减去最大值
3. exp_x = exp(x_shifted)                      // 计算指数
4. sum_exp = sum(exp_x, axis=dim, keepdims=True)  // 沿指定轴求和
5. y = exp_x / sum_exp                         // 归一化
6. return y
```

### 9. 边界条件处理
- **零值**: 正常计算
- **极值**: 使用 safe_softmax (减去最大值) 避免溢出
- **NaN/Inf**: 正常计算 (输入不应包含 NaN/Inf)
