# Matmul AllReduce + RMS Norm 融合算子

## 功能介绍
在模型训练/模型推理阶段，经过多头注意力机制后的输出会通过 PreNorm 的方式将结果进行数值归一化，以使得模型训练更加稳定。在 Qwen3 等 Decoder-Only 架构的模型中，RMS Norm 由于其计算复杂度低被广泛使用。同时，为了在分布式场景下提高模型的训练/推理速度，通常会通过 TP 并行将模型权重分散到两张卡上，通过集合通信的方式将计算结果聚合。Matmul AllReduce 在 MHA 中通过将各个头以及按行切分后对应输出头的权重分散到各卡上，完成各个头结果的聚合，输出结果如下：
$$
Y = Concat(h_0, h_1, ..., h_n) W_O
$$
省去了 Concat 操作的时间。
