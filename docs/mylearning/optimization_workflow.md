**版本：** 1.0  
**日期：** 2026-02-28  
**适用范围：** PyPTO 算子性能优化

## 1. 概述

本文档提供标准化的 PyPTO 算子性能优化工作流程，帮助开发者系统地进行性能优化。

### 1.1 优化流程总览

```
需求分析 → 方案设计 → 实现验证 → 性能测试 → 总结归档
    ↓           ↓           ↓           ↓           ↓
  明确目标    制定策略    编码实现    采集数据    文档记录
```

---

## 2. 阶段一：需求分析

### 2.1 明确优化目标

**检查清单：**
- [ ] 当前性能基线（执行时间）
- [ ] 目标性能（期望提升百分比）
- [ ] 精度要求（误差容忍度）
- [ ] 稳定性要求
- [ ] 资源约束（内存、计算资源）

### 2.2 收集性能数据

**步骤：**

1. **运行基线测试**
   ```bash
   export TILE_FWK_DEVICE_ID=0
   python test_operator.py
   ```

2. **采集性能指标**
   - 总执行时间
   - GM访问量
   - L2命中率
   - 核利用率

3. **生成泳道图**
   ```python
   @pypto.frontend.jit(
       debug_options={"runtime_debug_mode": 1}
   )
   ```

4. **分析性能瓶颈**
   - 查看 `output/output_*/merged_swimlane.json`
   - 使用 PyPTO Toolkit 可视化

### 2.3 识别优化点

**常见优化点：**

| 瓶颈类型 | 症状 | 优化方向 |
|----------|------|----------|
| GM访问过多 | MTE2占比较高 | Tile配置、L1复用 |
| 核利用率低 | 部分核空闲 | 并行循环、调度策略 |
| 循环开销大 | 循环次数多 | 循环展开、分块调整 |
| 内存带宽饱和 | 带宽利用率100% | 数据复用、缓存优化 |

## 3. 阶段二：方案设计

### 3.1 制定优化策略

**优先级排序：**

1. **P0 - 高收益低风险**
   - Tile配置调整
   - JIT参数调优
   - L1复用配置

2. **P1 - 中等收益中等风险**
   - 并行循环优化
   - 调度策略调整
   - 循环展开优化

3. **P2 - 高收益高风险**
   - 极限内存配置
   - 算法融合
   - 数据布局优化

### 3.2 设计多版本方案

**推荐做法：**

1. **稳健版本（V1）**
   - 采用P0级优化
   - 目标提升：30-50%
   - 风险：低

2. **激进版本（V2）**
   - 采用P0+P1级优化
   - 目标提升：50-70%
   - 风险：中高

## 5. 阶段四：性能测试

### 5.1 性能数据采集

**测试脚本模板：**

```python
def benchmark_versions():
    """对比多版本性能"""
    versions = [
        ('Baseline', operator_func_baseline),
        ('V1', operator_func_v1),
        ('V2', operator_func_v2)
    ]
    
    results = {}
    for name, func in versions:
        # Warmup
        for _ in range(3):
            func(*inputs)
        
        # Measure
        times = []
        for _ in range(10):
            start = time.time()
            func(*inputs)
            end = time.time()
            times.append((end - start) * 1000)
        
        results[name] = {
            'mean': np.mean(times),
            'std': np.std(times),
            'min': np.min(times),
            'max': np.max(times)
        }
    
    return results
```

3. **计算图指标**

## 8. 常见问题排查

### 8.1 性能未达预期

**排查步骤：**

1. **检查泳道图**
   - 找出最耗时的操作
   - 分析GM访问热点

2. **检查配置**
   - 确认Tile配置正确
   - 确认JIT配置生效

3. **尝试其他策略**
   - 调整调度模式
   - 调整循环展开
   - 增大内存配置

### 8.2 精度问题

**排查步骤：**

1. **定位误差来源**
   - 分段验证中间结果
   - 对比每个操作输出

2. **检查配置**
   - Tile配置是否过大
   - 数据类型转换是否正确

3. **调整容忍度**
   - 评估精度要求
   - 必要时降低优化程度

### 8.3 OOM问题

**排查步骤：**

1. **分析内存使用**
   - 检查Tile大小
   - 检查中间Tensor

2. **降低内存配置**
   - 减小stitch_function内存
   - 减小Tile大小

3. **优化数据流**
   - 减少中间结果
   - 及时释放内存
