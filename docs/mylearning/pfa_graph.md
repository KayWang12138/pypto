## 4. 五层循环迭代结构

### 4.1 循环嵌套图

```
┌─────────────────────────────────────────────────────────────────┐
│ for b_idx in range(b):              # batch 维度 (0 ~ 7)        │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ for s1_idx in range(s1):          # query位置 (0 ~ 127)     │ │
│ │ ┌─────────────────────────────────────────────────────────┐ │ │
│ │ │ cur_seq = s1_idx + 1    # 因果注意力: KV长度递增        │ │ │
│ │ │ s2_loop = ceil(cur_seq / s2_tile)                      │ │ │
│ │ │ ┌─────────────────────────────────────────────────────┐ │ │ │
│ │ │ │ for n2_idx in range(nkv):   # KV head (0)           │ │ │ │
│ │ │ │ ┌─────────────────────────────────────────────────┐ │ │ │ │
│ │ │ │ │ for g_idx in range(g_loop): # Q head组 (0)      │ │ │ │ │
│ │ │ │ │ ┌─────────────────────────────────────────────┐ │ │ │ │ │
│ │ │ │ │ │ 初始化: oi_update, sum_update, max_update  │ │ │ │ │ │
│ │ │ │ │ │ ┌─────────────────────────────────────────┐ │ │ │ │ │ │
│ │ │ │ │ │ │ for s2_idx in range(s2_loop):           │ │ │ │ │ │ │
│ │ │ │ │ │ │ │  # KV 分块迭代 (Flash Attention核心)  │ │ │ │ │ │ │
│ │ │ │ │ │ │ │  1. 组装 K/V block                    │ │ │ │ │ │ │
│ │ │ │ │ │ │ │  2. QK^T 计算                        │ │ │ │ │ │ │
│ │ │ │ │ │ │ │  3. Online Softmax                   │ │ │ │ │ │ │
│ │ │ │ │ │ │ │  4. PV 计算                          │ │ │ │ │ │ │
│ │ │ │ │ │ │ └─────────────────────────────────────────┘ │ │ │ │ │ │
│ │ │ │ │ │ │ 输出: oi_final = oi_update / sum_update    │ │ │ │ │ │
│ │ │ │ │ │ └─────────────────────────────────────────────┘ │ │ │ │ │
│ │ │ │ │ └─────────────────────────────────────────────────┘ │ │ │ │
│ │ │ │ └───────────────────────────────────────────────────┘ │ │ │
│ │ │ └───────────────────────────────────────────────────────┘ │ │
│ │ └───────────────────────────────────────────────────────────┘ │
│ └───────────────────────────────────────────────────────────────┘
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 循环变量说明

| 循环层 | 变量 | 范围 | 作用 |
|--------|------|------|------|
| 1 | `b_idx` | 0 ~ b-1 | 遍历 batch |
| 2 | `s1_idx` | 0 ~ s1-1 | 遍历 query 序列位置 |
| 3 | `n2_idx` | 0 ~ nkv-1 | 遍历 KV head |
| 4 | `g_idx` | 0 ~ g_loop-1 | 遍历 Q head 组 |
| 5 | `s2_idx` | 0 ~ s2_loop-1 | 遍历 KV 分块 |

### 4.3 关键偏移量计算

```python
# 代码位置: glm_attention_pfa.py:592-600

# Block 索引
idx = s2_idx * block_num  # s2_idx * 1 = s2_idx

# Batch-Sequence 偏移 (定位到具体 token)
bs_ofs = b_idx * s1_scalar + s1_idx
# 例如: b_idx=1, s1_idx=50 → bs_ofs = 1*128 + 50 = 178

# Head 组偏移 (定位到具体 head)
n1g_ofs = n2_idx * group + g_idx * g_tile
# 例如: n2_idx=0, g_idx=0, group=12 → n1g_ofs = 0

# 输出偏移 (写入结果的位置)
oi_ofs = [bs_ofs, n1g_ofs, 0]
# 例如: [178, 0, 0] → 写入 atten_out[178, 0:12, 0:128]
```

## 5. 因果注意力实现

### 5.1 因果掩码原理

```
因果注意力: Q[i] 只能看到 K[0:i+1] 和 V[0:i+1]

序列位置:    0    1    2    3   ...   127
           ┌────┬────┬────┬────┬─────┬─────┐
Q[0] ────> │ ✓  │ ✗  │ ✗  │ ✗  │ ... │ ✗   │  cur_seq = 1
           ├────┼────┼────┼────┼─────┼─────┤
Q[1] ────> │ ✓  │ ✓  │ ✗  │ ✗  │ ... │ ✗   │  cur_seq = 2
           ├────┼────┼────┼────┼─────┼─────┤
Q[2] ────> │ ✓  │ ✓  │ ✓  │ ✗  │ ... │ ✗   │  cur_seq = 3
           ├────┼────┼────┼────┼─────┼─────┤
Q[3] ────> │ ✓  │ ✓  │ ✓  │ ✓  │ ... │ ✗   │  cur_seq = 4
           ├────┼────┼────┼────┼─────┼─────┤
  ...      │ ...│ ...│ ...│ ...│ ... │ ... │
           ├────┼────┼────┼────┼─────┼─────┤
Q[127] ──> │ ✓  │ ✓  │ ✓  │ ✓  │ ... │ ✓   │  cur_seq = 128
           └────┴────┴────┴────┴─────┴─────┘

公式: cur_seq = s1_idx + 1
```

### 5.2 cur_seq 与 s2_loop 的关系

```
s1_idx  │ cur_seq  │ s2_loop = ceil(cur_seq/128)  │ KV blocks 需要处理
────────┼──────────┼──────────────────────────────┼────────────────────
   0    │    1     │         1                    │ 1 个 (部分)
   1    │    2     │         1                    │ 1 个 (部分)
  ...   │   ...    │        ...                   │ ...
  127   │   128    │         1                    │ 1 个 (完整)
────────┴──────────┴──────────────────────────────┴────────────────────

当 s1 = 128, s2_tile = 128 时:
- 每个 query 位置最多只需要处理 1 个 KV tile
- 但 effective tile size 不同 (actual_s2_tile)
```

### 5.3 actual_s2_tile 计算

```python
# 代码位置: glm_attention_pfa.py:599
actual_s2_tile = (cur_seq - s2_idx * s2_tile).min(s2_tile)
```

```
示例: s1 = 128, s2_tile = 128

s1_idx │ cur_seq │ s2_idx │ actual_s2_tile
───────┼─────────┼────────┼────────────────
   0   │    1    │   0    │  min(1, 128) = 1
   1   │    2    │   0    │  min(2, 128) = 2
   5   │    6    │   0    │  min(6, 128) = 6
  50   │   51    │   0    │  min(51, 128) = 51
 127   │   128   │   0    │  min(128, 128) = 128

actual_s2_tile 表示当前 tile 中有效的 KV 数量
用于 valid_shape 标记，避免计算无效位置
```

## 7. Online Softmax增量更新

### 7.1 算法原理

```
标准 Softmax:
  softmax(x_i) = exp(x_i) / Σ_j exp(x_j)

问题: 需要先计算所有 x_j 的 max 和 sum，无法分块

Online Softmax 解决方案:
  分块计算，增量更新 max 和 sum

假设已处理块:
  - max_old, sum_old, output_old

新块计算:
  - max_new = max(max_old, max_current)
  - correction = exp(max_old - max_new)
  - sum_new = sum_old * correction + sum_current
  - output_new = output_old * correction + output_current
```

### 7.2 增量更新图示

```
┌─────────────────────────────────────────────────────────────────────┐
│                    Online Softmax 增量更新                           │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │

│  │   [12, 1]         [12, 1]                                   │   │

│  │ 后续 tile (s2_idx > 0):                                      │   │
│  │                                                              │   │
│  │   sij = Q @ K^T                    [12, actual_s2_tile]     │   │
│  │          │                                                   │   │
│  │          ▼                                                   │   │
│  │   sij_scale = sij * scale         [12, actual_s2_tile]     │   │
│  │          │                                                   │   │
│  │          ▼                                                   │   │
│  │   tilda_mij = max(sij_scale)      [12, 1]                  │   │
│  │          │                                                   │   │
│  │          ▼                                                   │   │
│  │   max_new = max(max_update, tilda_mij)  [12, 1]            │   │
│  │          │                                                   │   │
│  │          ▼                                                   │   │
│  │   tsub = sij_scale - max_new       [12, actual_s2_tile]    │   │
│  │          │                                                   │   │
│  │          ▼                                                   │   │
│  │   tilda_pij = exp(tsub)           [12, actual_s2_tile]     │   │
│  │          │                                                   │   │
│  │          ▼                                                   │   │
│  │   sum_local = sum(tilda_pij)       [12, 1]                 │   │
│  │          │                                                   │   │
│  │          └────────────────────────────────┐                 │   │
│  │                                           ▼                 │   │
│  │   ┌─────────────────────────────────────────────────────┐  │   │
│  │   │ 校正因子计算:                                        │  │   │
│  │   │                                                      │  │   │
│  │   │ tsub2 = max_update - max_new    [12, 1]             │  │   │
│  │   │ update_mul = exp(tsub2)        [12, 1]              │  │   │
│  │   │                                                      │  │   │
│  │   │ sum_update = sum_update * update_mul + sum_local    │  │   │
│  │   │ max_update = max_new                                │  │   │
│  │   └─────────────────────────────────────────────────────┘  │   │
│  │                         │                                   │   │
│  │                         ▼                                   │   │
│  │              oi_tmp = P @ V      [12, 128]                 │   │
│  │                         │                                   │   │
│  │                         ▼                                   │   │
│  │   oi_update = oi_update * update_mul + oi_tmp              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                      │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │ 最后一个 tile (s2_idx = s2_loop - 1):                        │   │
│  │                                                              │   │
│  │   oi_final = oi_update / sum_update   [12, 128]            │   │
│  │          │                                                   │   │
│  │          ▼                                                   │   │
│  │   写入 atten_out[bs_ofs, n1g_ofs:n1g_ofs+g_tile, :]        │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

### 7.3 数值稳定性说明

```
为什么需要 max 校正?

假设 sij_scale = [100, 101, 102]

直接计算:
  exp([100, 101, 102]) = [2.7e43, 7.3e43, 1.98e44]  ← 溢出!

数值稳定版本:
  max = 102
  exp([100, 101, 102] - 102) = exp([-2, -1, 0])
                             = [0.135, 0.368, 1.0]  ← 正常

增量更新时:
  旧 max = 100, 新 max = 102
  correction = exp(100 - 102) = exp(-2) = 0.135
  旧的 sum 和 output 需要乘以 0.135 来校正
```
