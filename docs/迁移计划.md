```
any_cast.h 的作用
功能	             作用
DemangleTypeName	将混淆的 C++ 类型名转为人类可读格式
AnyCast	            增强版 std::any_cast，提供友好的错误信息（值拷贝）
AnyCastRef	        增强版 std::any_cast，提供友好的错误信息（返回引用，避免拷贝）


logging.h 的核心价值
功能        价值
多级日志    灵活控制输出详细程度
多种输出    开发时看控制台，生产环境写文件，测试时用内存
彩色输出    快速定位错误（红色）和警告（黄色）
CHECK 宏    简化错误处理，自动添加上下文信息
时间戳      精确定位问题发生时间
线程安全    多线程环境下安全使用
支持两种风格 流式日志 LOG_INFO 和 Printf风格LOG_INFO_F


error.h
ValueError  参数类型正确，但值不合法
TypeError   类型不匹配
RuntimeError 通用运行时错误
NotImplementedError 功能未实现
IndexError  索引越界
AssertionError 断言失败
InternalError  编译器内部错误（不应该发生的错误）

error.h 的核心价值
功能	价值
自动栈跟踪	快速定位错误源头，减少调试时间
Python 风格	与 Python 前端异常体系一致，易于理解
区分错误类型	用户错误 vs 系统错误，便于分类处理
零开销抽象	Release 模式下性能影响极小
详细调试信息	函数名、文件名、行号完整记录
配合logging.h实现自动俘获异常和打印功能


```

### 示例模式

```cpp
// structural_equal.cpp
bool StructuralEqual::VisitScalarType(const ScalarType* lhs, const ScalarType* rhs) {
    return lhs->dtype == rhs->dtype;
}

size_t StructuralHash::VisitScalarType(const ScalarType* node) {
    return hash_combine(node->dtype.code());
}
```
