## 1. Boost hash_combine 算法

### 1.1 技术背景

**来源：** Boost C++ 库的哈希组合算法

**核心特征：**
- 使用黄金比例常量 `0x9e3779b9` (约等于 2^32 / φ)
- 位运算公式：`seed ^ (value + 0x9e3779b9 + (seed << 6) + (seed >> 2))`
- 具有良好的雪崩效应，能均匀分布哈希值

### 1.2 在 pypto_open 中的使用情况

✅ **发现 3 处使用**

#### 1.2.1 位置1：通用哈希工具函数

**文件：** [framework/src/interface/utils/common.h:104-106](../framework/src/interface/utils/common.h#L104-L106)

```cpp
template <typename T>
inline void HashCombine(std::size_t &seed, const T &val) {
    seed ^= std::hash<T>()(val) + 0x9e3779b9 + (seed << 0x6) + (seed >> 0x2);
}
```

**特点：**
- ✅ 使用标准的 Boost 算法模式
- ✅ 黄金比例常量 `0x9e3779b9`
- ✅ 位移量 6 和 2 与 Boost 实现一致
- ✅ 提供了辅助函数 `HashVal` 支持可变参数

**应用场景：**
```cpp

    HashCombine(seed, val);
}

template <typename T, typename... Args>
inline void HashVal(size_t &seed, const T &val, const Args &...args) {
    HashCombine(seed, val);
    HashVal(seed, args...);
}
```

#### 1.2.2 位置2：算子张量参数哈希

**文件：** [framework/src/machine/runtime/device_launcher_binding.h:128-133](../framework/src/machine/runtime/device_launcher_binding.h#L128-L133)

```cpp
struct OperatorTensorParaHash {
    std::size_t operator()(const OperatorTensorPara& para) const {
        std::size_t hash = 0;
        hash_combine(hash, para.inputTensorParaList.size());
        for (const auto& tensor : para.inputTensorParaList) {
            hash_combine(hash, tensor.shape.dimSize);
            for (int i = 0; i < tensor.shape.dimSize; i++) {
                hash_combine(hash, tensor.shape.dim[i]);
            }
        }
        hash_combine(hash, para.outputTensorParaList.size());
        for (const auto& tensor : para.outputTensorParaList) {
            hash_combine(hash, tensor.shape.dimSize);
            for (int i = 0; i < tensor.shape.dimSize; i++) {
                hash_combine(hash, tensor.shape.dim[i]);
            }
        }
        return hash;
    }

private:
    template <class T>
    static void hash_combine(std::size_t& seed, const T& v) {
        std::hash<T> hasher;
        seed ^= hasher(v) + 0x9e3779b9 + (seed << 6) + (seed >> 2);
    }
};
```

**特点：**
- ✅ 使用标准 Boost 算法
- ✅ 作为私有成员函数封装在 struct 内
- ✅ 用于 `std::unordered_map` 的自定义哈希函数

**应用场景：**
用于缓存算子编译结果，以张量参数（形状）作为键值：

## 2. C++ ABI 符号解码 (__cxa_demangle)

### 2.1 技术背景

**来源：** Itanium C++ ABI 标准

**核心接口：** `abi::__cxa_demangle`
- 定义于 `<cxxabi.h>` 头文件
- 将修饰后的符号名（如 `N3std6vectorE`）转换为可读形式（如 `std::vector`）
- 被 GCC、Clang 等主流编译器实现

### 2.2 在 pypto_open 中的使用情况

✅ **发现 1 处使用**

**文件：** [framework/src/interface/utils/error.cpp:184-189](../framework/src/interface/utils/error.cpp#L184-L189)

```cpp
int status = 0;
std::unique_ptr<char, std::function<void(char *)>> demangled(
    abi::__cxa_demangle(funcName, nullptr, nullptr, &status),
    /* deleter */ free);
if (status == 0)
    funcName = demangled.get();
```

**上下文：**
这段代码位于 `BacktraceImpl::ParseFrame` 函数中，用于在堆栈回溯时解码C++函数名。

**完整实现：**
```cpp
void ParseFrame(std::stringstream &ss, char *line, void* addr, bool &isPyptoFrame) const {
    auto funcName = strchr(line, '(');
    auto funcOffset = strchr(line, '+');
    auto libname = strrchr(line, '/');
    if (funcName == nullptr || funcOffset == nullptr) {
        ss << line <<'\n';
        return;
    }

    *funcName++ = '\0';
    *funcOffset++ = '\0';
    libname = (libname == nullptr) ? line : libname + 1;
    if (!strncmp(libname, "pypto_impl", strlen("pypto_impl"))) {
        isPyptoFrame = true;
    } else if (isPyptoFrame) {
        // python frames after pypto frame, skip it
        return;
    }

    int status = 0;
    std::unique_ptr<char, std::function<void(char *)>> demangled(
        abi::__cxa_demangle(funcName, nullptr, nullptr, &status),
        /* deleter */ free);
    if (status == 0)
        funcName = demangled.get();

    // Try to get file and line information using addr2line
    FileLocation loc = GetFileLineFromAddr2line(addr);

    if (!loc.filename.empty() && loc.lineno > 0) {
        // Python-style format: File "filename", line X
        ss << " File \"" << loc.filename << "\", line " << loc.lineno << "\n";

        // Display source code line if available
        std::string sourceLine = ReadSourceLine(loc.filename, loc.lineno);
        if (!sourceLine.empty()) {
            ss << "   " << sourceLine << "\n";
        }
    } else {
        // Fallback to traditional format if addr2line fails
        ss << libname << '(' << funcName << '+' << funcOffset << '\n';
    }
}
```

```cpp
        auto it = locMap.find(addr);

        }
```

```cpp
static std::string ReadSourceLine(const std::string& filename, int lineno) {
    std::ifstream file(filename);
    if (!file.is_open()) {
        return "";
    }

    std::string line;
    int current_line = 0;
    while (std::getline(file, line)) {
        current_line++;
        if (current_line == lineno) {
            // Trim leading whitespace for display
            size_t start = line.find_first_not_of(" \t");
            if (start != std::string::npos) {
                return line.substr(start);
            }
            return line;
        }
    }
    return "";
}
```

3. **Python风格格式化**（[error.cpp:217-228](../framework/src/interface/utils/error.cpp#L217-L228)）
```cpp
const std::string &Get() const {
    return symbols_.Ensure([this]() -> std::string {
        auto strings = backtrace_symbols(callStack_.data(), callStack_.size());
        if (strings == nullptr) {
            return "Backtrace Failed";
        }
        std::stringstream ss;

        // Add Python-style traceback header
        ss << "\nC++ Traceback (most recent call last):\n";

        bool isPyptoFrame = false;
        // Reverse the frames to show most recent last (Python style)
        for (int i = static_cast<int>(callStack_.size()) - 1; i >= 0; i--) {
            ParseFrame(ss, strings[i], callStack_[i], isPyptoFrame);
        }
        free(strings);
        return ss.str();
    });
}
```
