## 功能说明<a name="section618mcpsimp"></a>

对 input 和 other 进行逐元素大于等于比较。

## 函数原型<a name="section8786125214915"></a>

```
ge(input: Tensor, other: Tensor) -> Tensor
```

## 返回值说明<a name="section640mcpsimp"></a>

返回一个布尔张量，在 input 大于等于 other 的值为 True，其余值为 False。与输入张量形状相同的布尔张量

## 约束说明<a name="section753174210543"></a>

无。

## 调用示例<a name="section642mcpsimp"></a>

```
a = pypto.tensor([3], pypto.DT_FP32)
b = pypto.tensor([3], pypto.DT_FP32)
out = pypto.ge(a, b)
```

结果示例如下：

```
输入数据a: [1, 2, 3]
输入数据b: [2, 2, 2]
输出数据out: [False, True, True]
```
