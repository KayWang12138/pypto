# pypto.set\_codegen\_options

## Supported Products

| Product             | Supported |
|:-----------------|:--------:|
| Atlas A3 Training Series/Atlas A3 Inference Series |    √     |
| Atlas A2 Training Series/Atlas A2 Inference Series |    √     |

## Description

Sets codegen options.

## Function Prototype

```python
set_codegen_options(*, support_dynamic_aligned: bool = None) -> None
```

## Parameters


| Parameter                      | Input/Output | Description                                                                 |
|-----------------------------|-----------|----------------------------------------------------------------------|
| support_dynamic_aligned     | Input      | Meaning: Whether to support dynamic shape. <br> Description: <br> When set to True, the device-side binary generated by the operator supports aligned dynamic shape scenarios. <br> When set to False, the device-side binary generated by the operator only supports non-aligned dynamic shape scenarios. <br> Type: bool <br> Value range: {True, False} <br> Default: False (when the operator confirms dynamic shape and all shape tail axes are aligned, you may try enabling this to check for performance gains) <br> Affected pass scope: None — only affects the device-side target code generated by the CodeGen module |


## Return Value

void: Set methods have no return value. The setting takes effect immediately upon success.

## Constraints

The effect of the support\_dynamic\_aligned option will be optimized via the Pass inference mechanism in the future and will no longer need to be set manually. Users are advised to use this option with caution.

## Example

```python
pypto.set_codegen_options(support_dynamic_aligned=True)
```
