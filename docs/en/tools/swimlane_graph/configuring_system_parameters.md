# Configuring Swimlane Graph System Parameters

## Feature Description

Supports customizing the maximum display level of the swimlane graph, as well as shortcut keys for moving and zooming.

## Steps

1.  Right-click the PyPTO Toolkit plugin name, select **"Extension Settings"**, and enter the configuration panel interface.
2.  Select **"Extensions > PyPTO Toolkit > Swimlane Diagram"** to customize the configuration scheme. For example:
