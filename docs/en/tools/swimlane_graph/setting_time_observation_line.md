# Setting a Time Observation Line

## Feature Description

By hovering over or clicking on the time axis, an observation line appears, allowing users to observe the current moment and better leverage the swimlane graph for debugging and optimization.

## Prerequisites

Execute the PyPTO program to generate the swimlane graph file.

## Steps

1.  Open the swimlane graph file. Two methods are available:
    1.  In the Visual Studio Code sidebar, click the ![](../../../tools/figures/zh-cn_image_0000002491265870.png) icon to open PyPTO Toolkit, then open the swimlane graph file in the run results interface.
    2.  In the Visual Studio Code workspace, right-click the swimlane graph file and select **"PyPTO Toolkit: Open File"** from the pop-up menu.

2.  Open the swimlane graph and hover the mouse over the time axis. An observation line appears and moves with the mouse.

    ![](../../../tools/figures/zh-cn_image_0000002520859995.png)

3.  Click on the time axis to add a fixed time observation line, which can be used as a reference marker when observing the swimlane graph.

    ![](../../../tools/figures/zh-cn_image_0000002520740073.png)

4.  Click the flag on the observation line to delete or modify it.

    ![](../../../tools/figures/zh-cn_image_0000002488660762.png)

    Modification supports changing the color of the observation line or setting a custom label.

    ![](../../../tools/figures/zh-cn_image_0000002488500850.png)
