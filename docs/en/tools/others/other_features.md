# Other Features

## One-Click Close All Plugin Pages

### Feature Description

When many pages have been opened by the tool, if you need to close all tool-generated pages at once, you can use the **"PyPTO Toolkit: Close All Tool Pages"** menu to close all pages opened by the plugin in one click.

### Prerequisites

Execute the PyPTO program and successfully generate a swimlane graph, computation graph, or three-column linked view.

### Steps

1.  In the file tab area of any tool-generated page, right-click and select the **"PyPTO Toolkit: Close All Tool Pages"** menu option to close all tool-generated pages in one click. ![](../../../tools/figures/zh-cn_image_0000002533790935.png)
