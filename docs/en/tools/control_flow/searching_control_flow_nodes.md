# Searching Control Flow Graph Nodes

## Feature Description

After opening the control flow graph interface, you can perform a fuzzy search for LOOP or PATH node names within the control flow.

## Steps

1.  In the run results interface, click **"Results Overview"** to open the control flow graph.
2.  In the search bar at the top right, enter a LOOP or PATH node name as the search keyword.

    ![](../../../tools/figures/zh-cn_image_0000002502189100.png)

3.  Select a search result to navigate to the corresponding node in the current graph.
