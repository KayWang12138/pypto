# Introduction

PyPTO Toolkit is a full-lifecycle assistant tool for the PyPTO framework. It provides visualization of compilation and runtime states as well as operator development workflow capabilities, enabling developers to quickly build an understanding of the PyPTO framework and improve the efficiency of operator development, debugging, and optimization.

## Core Features

-   **Control flow visualization**: Visualizes the computation logic expressed using the PyPTO framework, and provides a mapping view among computation logic expression code, control flow graphs, and computation graphs.
-   **Computation graph**: Based on the foundational graph structure of Tensors and Operations, it provides full-pipeline visualization of the compilation process from the original computation graph to the executable graph.
-   **Swimlane graph**: Provides visualization of inter-core and intra-core pipelines and statistical information, supporting task dependency analysis and multi-dimensional statistical report display.
-   **Three-column linked view**: Supports real-time linkage among operator code, computation graph, and swimlane graph, lowering the barrier to debugging and optimization with the PyPTO framework and improving all-in-one debugging and optimization efficiency.
