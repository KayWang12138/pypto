# Installation

## Prerequisites

Visual Studio Code must already be installed, with a version of 1.94.1 or later.

## Steps

To install the PyPTO Toolkit plugin:

1.  Click [LINK](https://ascend-cann.obs.cn-north-4.myhuaweicloud.com/devkit/pypto-toolkit-1.1.0.vsix) to download the plugin.
2.  Open Visual Studio Code, go to the **Extensions** tab, click **"..."** in the upper-right corner, and select **"Install from VSIX..."**.

    **Figure 1**  Installing the PyPTO Toolkit plugin
    ![](../../../tools/figures/install.png)

3.  Select the `.vsix` plugin file to complete the installation.
