# PyPTO Documentation Center

Welcome to the PyPTO documentation. This documentation is primarily authored by Huawei Technologies Co., Ltd. and includes contributions from CANN community contributors. Huawei Technologies Co., Ltd. and CANN community contributors reserve all rights to the content of this documentation.

PyPTO (pronounced: pai p-t-o) is a high-performance programming framework for AI accelerators launched by CANN, designed to simplify the operator development process while maintaining high-performance computing capabilities. The framework adopts the innovative PTO (Parallel Tensor/Tile Operation) programming paradigm, with a Tile-based programming model as its core design philosophy. Through multi-level computation graph representation, it progressively compiles AI models built by users via the API from high-level Tensor computation graphs into hardware instructions, ultimately generating code that can be efficiently executed on the target platform, dispatched by the device side in MPMD (Multiple Program Multiple Data) fashion.
