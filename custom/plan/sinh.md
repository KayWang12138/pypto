# Sinh 算子开发总结

## 开发状态

✅ **开发成功**

## 需求信息

- **算子名称**：sinh
- **数学公式**：y = sinh(x) = (e^x - e^{-x}) / 2
- **输入规格**：[b, s, n, d], float32
- **输出规格**：[b, s, n, d], float32
- **精度标准**：atol=0.000025, rtol=0.005

## 实现方案

### API 组合

通过组合以下 PyPTO API 实现：

1. `pypto.exp(x)` - 计算 e^x
2. `pypto.neg(x)` - 取负得到 -x
3. `pypto.exp(neg_x)` - 计算 e^{-x}
4. `pypto.sub(exp_x, exp_neg_x)` - 计算 e^x - e^{-x}
5. `pypto.div(diff, 2.0)` - 除以 2
